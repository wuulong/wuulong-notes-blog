# 蘭陽溪流域探索：二日垂直地景巡禮計畫 (v2.0)

蘭陽溪不僅是地理上雪山與中央山脈的分界，更是台灣東北部最重要、最具多樣性的生命線。從海拔 1,948 公尺的思源埡口到太平洋岸，本計畫將運用「垂直地景」與「物件導向歷史 (OO-History)」視視角，解析這場跨越地質、電力、族群與農業歷史的深度讀圖之旅。

## 📅 每日行程與預計點位

### **Day 1：垂直地景與權力網絡 —— 高山、翻越與監控**
這一天我們將站在蘭陽溪的最上游，探訪分水嶺與那些隱藏在沖積扇背後的族群權力重構歷程。

1. **思源埡口 (Siyuan Watershed)**：蘭陽溪與大甲溪的分界點，觀察垂直地景的最上層特徵。
2. **南山村 (埤亞南社 / Pyanan)**：泰雅族聚落與扇端湧泉、高冷蔬菜產業的地景對合。特別關注「加腦蘭 (Kanan)」原始社址與日治「警察駐在所」的視線監控關係。
3. **馬諾源平台 (Mnoyan)**：消失的聚落點位。探討日治時期生活空間如何被轉化為「四季村」的純生產空間（耕地）。
4. **牛鬥橋 (Niudou)**：蘭陽溪峽谷收束點，也是地理上山區與平原的分界門戶。

### **Day 2：地質適應與治理邊界 —— 發電、西瓜、湧泉與出海口**
探索蘭陽溪如何從一條「荒溪」轉化為宜蘭現代化的能源與產業核心，並在入海口見證它的終結。

1. **天送埤車站 / 蘭陽發電廠**：日治時期宜蘭工業化的樞紐。觀察蘭陽溪水如何被導入太平山森鐵與電力系統。
2. **三星西瓜地景**：觀察板岩沖積扇地質如何形塑獨特的「浮腹地」農業，解析西瓜根系與砂質土的地質決定論。
3. **員山取水口 (天然自湧泉)**：觀察「隱形水庫」的伏流噴湧，理解蘭陽平原的高效大地過濾機制。
4. **五結防潮閘門與壯圍沙丘**：觀察防潮閘門如何阻絕鹹水倒灌，以及出海口地形演替的動態美學。
5. **蘭陽溪口 (出海口)**：三水匯流處，蘭陽溪海拔 0 公尺的終點演替。
