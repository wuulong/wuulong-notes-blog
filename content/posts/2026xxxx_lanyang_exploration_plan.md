# 蘭陽溪流域探索：二日深度巡禮計畫

蘭陽溪不仅是地理上雪山與中央山脈的分界，更是台灣東北部最重要、最具多樣性的生命線。從上游的泰雅族传统領域，到中游的電力與西瓜產業，再到下游的防洪大計，蘭陽溪展示了人類如何與「不穩定地質」共生的極致智慧。

## 📅 每日行程與預計點位

### **Day 1：垂直地景的起點 —— 高山、翻越與強制遷徙**
這一天我們將站在蘭陽溪的最上游，探訪分水嶺與那些躲在沖積扇背後的歷史。

1. **思源埡口 (Siyuan Watershed)**：蘭陽溪與大甲溪的分界點，觀察垂直地景的最上層特徵。
2. **南山村 (埤亞南社 / Pyanan)**：泰雅族聚落與扇端湧泉、高冷蔬菜產業的地景對合。
3. **牛鬥橋 (Niudou)**：蘭陽溪峽谷收束點，也是地理上山區與平原的分界門戶。

### **Day 2：流域的能量與治理 —— 發電、西瓜、閘門與出海口**
探索蘭陽溪如何從一條「荒溪」轉化為宜蘭現代化的能源與產業核心，並在入海口見證它的終結。

1. **天送埤車站 / 蘭陽發電廠**：日治時期宜蘭工業化的樞紐與水利控制點。
2. **三星西瓜田**：觀察板岩沖積扇地質如何形塑獨特的浮腹地農業。
3. **五結防潮閘門與壯圍沙丘**：防洪大計與出海口地形演替的動態美學。
4. **蘭陽溪口 (出海口)**：三水匯流處，蘭陽溪海拔 0 公尺的終點演替。
