# 竹塹五書歷史知識地圖

## 簡介 (Introduction)
本計畫致力於將新竹地區最具代表性的五部歷史文獻（簡稱「竹塹五書」）與現代地理資訊系統 (GIS) 進行深度對位。透過對《新竹縣採訪冊》等史料中記載的聚落、圳路、古蹟及地景進行座標化，結合 1920 年代的台灣堡圖與現今的數值地形模型 (DTM)，重建三百年間竹塹地區的時空演變。
