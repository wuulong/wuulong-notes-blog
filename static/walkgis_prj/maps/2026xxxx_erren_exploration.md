# 🌊 二仁溪流域探索地圖 (Erren River ISMap)

本計畫結合《南部紋理》8.3 節「環境博物館」概念，將二仁溪視為一個動態的環境實驗場。

 ```mermaid
    end
     
     Sub1[三爺溪] --> Lower

     Sub3[牛稠埔溪] --> Middle
 ```
 
## 🗺️ 空間分區導引 (Regional Guide)

- **Day 1: 惡地與起源 (Upper Stream)**：聚焦於二仁溪劇烈的輸砂源頭與泥岩地景。
    - 點位：[二仁溪源頭](../features/20260204_erren_source.md)、[308高地](../features/20260204_erren_308_high.md)、[田寮月世界](../features/20260204_erren_moon_world.md)。
- **Day 2: 鐵道與糖業 (Middle Stream)**：探索「界河」兩側的工業物資動脈與糖業研究遺產。
    - 點位：[阿蓮大曲流](../features/20260204_erren_fuxing_meander.md)、**[二層行溪舊鐵路橋](?map=national_exploration_spots&feature=20260315_二層行溪舊鐵路橋)**、**[保安車站](?map=national_exploration_spots&feature=20260315_保安車站)**、**[台灣糖業試驗所](?map=national_exploration_spots&feature=20260315_台灣糖業試驗所)**。
- **Day 3: 治理、修復與重生 (Lower Stream)**：從全台最毒河流到環境博物館的轉型歷程。
    - 點位：[港尾溝分洪道](../features/20260204_erren_gangweigou_diversion.md)、[仁德滯洪池](../features/20260204_erren_rende_pond.md)、[南萣橋遺址](../features/20260204_erren_nanding_legacy.md)、[茄萣舢筏協會](../features/20260204_erren_sampan_assoc.md)。
