# 曾文溪水利與生態探索地圖 (2026)

曾文溪為嘉南平原的母河，本計畫透過 WalkGIS 紀錄從源頭水庫到海口防潮體系的關鍵節點，特別著重於日治時期至今的水利演變。

## 💧 水利焦點：嘉南大圳與現代防淤
曾文溪流域的水利工程橫跨百年：
- **上游：防淤永續**：曾文水庫防淤隧道（象鼻引水工）展現了現代應對水庫淤積的工程智慧。
- **中游：生命線**：渡槽橋群（曾文、官田、茄拔）是嘉南大圳將水送往平原乾涸之地的關鍵體系。
- **下游：守護邊界**：海口防潮大堤與排水閘門，是與海爭地的防災最前線。
