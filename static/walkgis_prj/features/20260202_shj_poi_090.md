# 梅花飯店水庫店 (Plum Blossom Dam Restaurant)

![20260202_shj_poi_090](https://lh3.googleusercontent.com/gps-cs-s/AHVAweqnKF-JHfOxYWOm_Ftq1AEzuKMnQz_ea2QkU0J83nUPmIgC1k4_XGoqjZvYrjR03u7vKwo64Y7rJvaZfOMXPxbxsrWOWQMh58_hMPFrvHR-kC9fqvZQaYhAHHuDCNhMr0Xy8L0MSiDzXSeH=s1600-w1200)


梅花飯店位於曾文水庫園區內，鄰近趣淘漫旅與青年活動中心。這是一間以「曾文溪流域美食」聞名的老字號合菜餐館，是山海圳旅人進入水庫核心區後品味在地活魚的首選據點。

## 🔍 特色與細節
*   **曾文三寶美食**: 餐廳主打曾文水庫產的砂鍋魚頭、鮮美筍殼魚與極具特色的「三杯魚虎」。魚虎為水庫外來入侵種，經廚師巧手轉化為彈牙美味，既具備環保意義又是獨特食記。
*   **深山人情味**: 服務親切且份量十足，是許多機關團體與登山小組聚餐的共同記憶。
*   **經典店貌**: 保留了台灣早期風景區餐館的樸實感，在高樓飯店林立的水庫區提供了一種踏實的溫度。

## 💡 旅人筆記
*   **必點推薦**: 砂鍋魚頭是這裡的鎮店之寶，湯頭濃郁、魚塊飽滿，非常適合多人分食以補充健行後的蛋白質。
*   **公休提醒**: 固定於每週三公休，行程安排時請務必留意，避免撲空。
*   **位置便利**: 距離週邊飯店均在步行範圍內，是水庫夜間外出的用餐良伴。
