# 公塭仔 萬安宮 (Gongwenzai Wan-An Temple)

![20260130_zengwen_公塭仔萬安宮](https://lh3.googleusercontent.com/gps-cs-s/AHVAwep8QCYrq5s3TalWskSXkZcJD3VCfqPF8djlrVHu2iC1rpE21wJZuXdQIwvAqwT1HQw9-1Gz2XsAj0O-Sc9MUy1TWgy2tUQTBPZOZpGxPo4kuDdoCtFwOSsFiFnOPT87W3sLQ-MV=s1600-w1200)


## 簡介
與溪埔寮安溪宮並列，這裡居住的是 1911 年曾文溪大改道中被沖毀的「蚵殼港」庄遺民。

## 觀察重點
- **蚵殼港滅庄史**：了解 1911 年（明治 44 年）大洪水如何終結了繁榮的蚵殼港庄，迫使居民分流遷徙至海口浮覆地。
- **百足真人**：公塭仔萬安宮與溪埔寮安溪宮共同組成的「百足真人」蜈蚣陣，是西港刈香中最震撼的視覺景觀，象徵著兩村庄血脈相連的共同歷史記憶。
- **防禦地景**：觀察遷村後的聚落選址如何兼顧排水與生存，看見遺民如何在感潮帶重建家園。
