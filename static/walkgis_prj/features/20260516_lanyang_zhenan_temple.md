# 太平山鎮安宮 (Zhen'an Temple)

## 📌 空間屬性
- **座標**：24.4938228, 121.5350764
- **海拔**：約 2,000 公尺 (宜蘭最高廟宇)
- **類型**：信仰空間 / 歷史建築

## 📜 OO-History 考掘
- **【政權移轉】**：前身為日治時期的「太平山神社」。戰後改奉鄭成功，現改名鎮安宮。這個空間物件體現了不同政權如何透過改變「信仰對象」來繼承對資源開發的合法性與統治權威。
- **【空間定錨】**：位於太平山莊中央階梯頂端，是整個林場的精神地標。

## 📸 現場觀察筆記 (2026-05-16)
- 廟宇建築保留了部分神社的基座遺構，形成一種獨特的文化層疊現象。
- 拾級而上的過程，本身就是一種對自然與權威的朝聖。
