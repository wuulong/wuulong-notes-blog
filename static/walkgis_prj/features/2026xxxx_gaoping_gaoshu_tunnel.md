# 高樹隘寮堤防(龍貓秘境)：壯闊匯流點

![2026xxxx_gaoping_gaoshu_tunnel](https://lh3.googleusercontent.com/gps-cs-s/AHVAweruALHkCcatUCIGyWsfvf9qD8ufpEfZk962tURhVI7R8ZWtEH7toYJZzpVghzxvytxMLsk_3wa2BXEJB8zRN0SL_sb--SfQan9Ho-DsYUHKkvYD7N_tEkwQDyqY41c7q6Tv6cipNNC8DLni=s1600-w1200)


## 📜 歷史與地景背景
三水交匯能量最強處。站在隘寮堤防可以俯瞰壯觀的河川匯流與遠方大武山輪廓。

## 🔍 流域深度解讀
荖濃溪與隘寮溪在此匯合成為高屏溪。站在堤防上，兩側綠蔭如織形成「龍貓隧道」，是觀察巨大河床變遷的絕選。

## ✨ 亮點特色
- 壯闊匯流點
- 龍貓綠色隧道
- 採砂地貌觀測
