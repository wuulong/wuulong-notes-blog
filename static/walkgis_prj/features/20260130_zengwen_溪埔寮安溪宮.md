# 溪埔寮 安溪宮 (Xipuliao Anxi Temple)

## 簡介
與公塭仔萬安宮共同組成「蚵殼港」庄的歷史殘影。居民在曾文溪「青瞑蛇」肆虐後，在此處溪埔地（沙洲浮覆地）紮根。

## 觀察重點
- **扛茨走溪流**：此聚落居民曾頻繁實踐「扛茨走溪流」——即當大水將至，集體抬起柔性建築的「竹籠茨」遷移，展現了與河共處的極度韌性。
- **蜈蚣陣兄弟情**：安溪宮與萬安宮在宗教儀式上的深度耦合，提醒著後世他們曾是同一個庄頭的兄弟。
- **溪埔地開墾**：觀察土地利用如何從荒蕪的沙地轉化為肥沃的耕作區，理解泥沙沉積帶來的「災難與饋贈」。
