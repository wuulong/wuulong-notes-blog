# 官田溪渡槽橋

![20260128_zengwen_官田溪渡槽橋](https://upload.wikimedia.org/wikipedia/commons/d/d6/%E5%98%89%E5%8D%97%E5%A4%A7%E5%9C%B3%E5%AE%98%E7%94%B0%E6%BA%AA%E6%B8%A1%E6%A7%BD%E6%A9%8B.jpg)


## 簡介
嘉南大圳跨越官田溪的水道橋。與曾文溪渡槽橋、茄拔溪渡槽橋併稱為嘉南大圳三大渡槽橋。

## 觀察重點
- **桁架結構**：觀察日治時期鋼結構工法。
- **水流方向**：確認嘉南大圳支線如何引導水源。
- **產業連結**：了解此區域與周邊農田灌溉之關係。
