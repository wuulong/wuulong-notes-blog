# 住-特富野民宿 (Tefuye Guesthouse)

![20260202_shj_poi_074](https://lh3.googleusercontent.com/places/ANXAkqG_m8nSa2VP61LYEukN9whrN8kZsul9LKkrpcwVtFw33_7CvdgJHIJjY1C-4Y7A1VoN5d9Xg9GxcJrKRd5jQ54_rNVZ_7UJOfA=s1600-w1076)


特富野民宿座落於阿里山鄒族特富野大社內，是山海圳國家綠道「原鄉之路」旅程中，深度體驗部落文化最推薦的下榻點。

## 🔍 特色與細節
*   **大社核心位置**: 民宿與鄒族神聖的集會所「庫巴」(Kuba) 僅有數百公尺之遙。早晨醒來，空氣中瀰漫著山林的清新與部落悠久的氣息。
*   **護照優惠驛站**: 作為官方合作的住宿服務點，持山海圳護照在此訂房可享有專案優惠（請預約時告知並出示護照）。
*   **原民款待**: 提供溫馨舒適的雅房與套房。民宿主人不僅是優質的宿主，更是部落文化的守門人。

## 💡 旅人筆記
*   **文化洗禮**: 入住此地即正式進入鄒族的核心精神領域。建議在部落內散步時保持虔誠心態，觀察不同氏族的象徵符號。
*   **星空景觀**: 陽台望出去，夜晚若天氣晴朗可見到如鑽石般的星空，與「內海之路」的城市光害形成強烈對比。
*   **備忘提醒**: 山區資源物資取得不易，請自備個人特定盥洗用品。
