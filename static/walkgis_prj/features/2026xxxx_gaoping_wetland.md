# 大樹舊鐵橋濕地：自然腎臟修復

![2026xxxx_gaoping_wetland](https://upload.wikimedia.org/wikipedia/commons/thumb/6/6f/%E9%AB%98%E5%B1%8F%E6%BA%AA%E8%88%8A%E9%90%B5%E6%A9%8B%E6%BA%BC%E5%9C%B0%E5%85%AC%E5%9C%92.jpg/1280px-%E9%AB%98%E5%B1%8F%E6%BA%AA%E8%88%8A%E9%90%B5%E6%A9%8B%E6%BA%BC%E5%9C%B0%E5%85%AC%E5%9C%92.jpg)


## 📜 歷史與地景背景
高屏溪曾是「黑水溝」。離牧政策配合此人工濕地，成功改善水質，目前為公私協力（PPP）治理典範。

## 🔍 流域深度解讀
利用人工濕地淨化工業廢水的典範。引入永豐餘造紙廠放流水，透過自然工法三級處理，重現盎然生機。

## ✨ 亮點特色
- 自然腎臟修復
- 造紙廠廢水轉生
- 水雉回歸綠洲
