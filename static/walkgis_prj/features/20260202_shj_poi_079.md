# 住-烏山頭湖境渡假會館 (Hujing Resort)

![20260202_shj_poi_079](https://lh3.googleusercontent.com/gps-cs-s/AHVAweqqoV774QUpxjqb1WsFJ-o6vXJvOLk_jsgRVaS1HoMYGwuyw1UbjH6C5ViVYFdhAjiuGdep9gGhY83jeBnI_edvIaVnXI89J5XCVSTTYWeDJevOWuaDTlEYYahspDgEAqrzwiKMig=s1600-w1200)


湖境渡假會館座落於烏山頭水庫風景區內，佔據半山腰視野最佳處，是山海圳綠道「大圳之路」上景觀最為壯麗的住宿選擇。

## 🔍 特色與細節
*   **大圳史蹟門戶**: 會館鄰近八田與一銅像與大壩。旅人清晨醒來，可直接俯及湖面倒映的絕美朝霞。
*   **護照優惠驛站**: 官方認證的合作夥伴。持山海圳護照在此訂房，可享有專為徒步挑戰者量身打造的優惠方案。
*   **精緻放鬆**: 提供具備景觀窗的各類型客房與完備餐飲服務。

## 💡 旅人筆記
*   **行程調節點**: 建議在此住宿，並利用傍晚時間悠閒散步香榭大道，體會當年建造大圳時的歷史厚度。
*   **入園優惠**: 住宿旅人購買烏山頭水庫門票可享有相關折抵（依會館最新公告為準）。
*   **高山前哨**: 這裡是翻越烏山嶺、離開西部平原進入深山部落前的最後「文明奢華」，值得在此好好修整體能。
