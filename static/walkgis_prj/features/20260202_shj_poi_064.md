# 隆本復興宮 (Longben Fuxing Temple)

![20260202_shj_poi_064](https://upload.wikimedia.org/wikipedia/commons/thumb/3/31/%E9%9A%86%E6%9C%AC%E5%BE%A9%E8%88%88%E5%AE%AE%E8%88%87%E9%87%8D%E5%BB%BA%E5%BE%8C%E7%9A%84%E7%95%AA%E4%BB%94%E7%94%B0%E5%A4%A7%E5%85%AC%E5%BB%A8.jpg/1280px-%E9%9A%86%E6%9C%AC%E5%BE%A9%E8%88%88%E5%AE%AE%E8%88%87%E9%87%8D%E5%BB%BA%E5%BE%8C%E7%9A%84%E7%95%AA%E4%BB%94%E7%94%B0%E5%A4%A7%E5%85%AC%E5%BB%A8.jpg)


隆本復興宮位於台南市官田區隆本里，舊稱「番仔田」。這裡是西拉雅族重要的文化中心，廟內不僅奉祀漢式神明，更保有全國規模宏大且歷史悠久的西拉雅族公廨信仰空間。

## 🔍 特色與細節
*   **廟中廟與公廨**: 復興宮的主殿奉祀太上老君、關聖帝君等神祇，而其前身即為番仔田部落的公廨。如今在廟埕廣場前仍搭設有傳統的西拉雅公廨，供奉阿立祖。
*   **阿立祖與大內夜祭**: 隆本復興宮的夜祭（農曆十月十四、十五日）是當地極為重要的文化活動，族人會進行點豬、跳戲等傳承百年的祭祀儀典。
*   **西拉雅文化發源地**: 「番仔田」之名見證了清代以來西拉雅族居住於此的歷史。復興宮的存在是族群漢化過程中，仍積極保留原鄉信仰之魂的珍覺典範。

## 💡 旅人筆記
*   **文化停靠站**: 這裡是山海圳「大圳之路」段落中最具西部平原人文色彩的景點之一。旅人可在此同時觀察到漢人祖先與西拉雅祖靈在同一神聖空間下的和諧共處。
*   **推薦順遊**: 鄰近隆田車站與隆田 chacha 文化園區，是規劃半日輕旅行的理想節點。
*   **尊重禁忌**: 雖然復興宮外觀如一般廟宇，但進入前方的公廨空間時，仍請保持虔誠與尊重，勿隨意撥動祭壇物品。
