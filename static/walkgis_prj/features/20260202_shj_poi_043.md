# 西口工作站 (西口小瑞士)

![20260202_shj_poi_043](https://upload.wikimedia.org/wikipedia/commons/thumb/2/24/%E9%9D%A2%E5%9F%8E%E6%A8%93%E9%9B%86%E9%88%94%28%E4%B8%89%29.djvu/page1-1280px-%E9%9D%A2%E5%9F%8E%E6%A8%93%E9%9B%86%E9%88%94%28%E4%B8%89%29.djvu.jpg)


西口工作站位於台南市東山區，是烏山嶺引水道的西端出水口。此地因其優美的河谷景致與著名的水利工程奇觀「天井漩渦」，而被譽為「西口小瑞士」。

## 📜 歷史背景 (Historical Context)
*   **東西口引水工程**: 為了補足烏山頭水庫的水源，八田與一技師於 1920 年代規畫於烏山嶺開鑿引水道，將曾文溪水從「東口」引入，穿越山嶺後由「西口」流出，歷經七年艱辛完工。
*   **水利碑石**: 西口工作站後方立有民國 36 年（1947年）的「修建嘉南大圳記」花崗石碑，不僅記述了水利系統的維護歷史，也為戰後台灣農業基礎的修復留下了見證。
*   **駐在所演變**: 此地早年曾是防砂造林駐在所，現為農業部農田水利署嘉南管理處的辦公據點。

## ✨ 亮點特色 (Highlights & Features)
*   **天井漩渦 (The Whirlpool)**:
    - 這裡最震撼的視覺景觀。當曾文溪水從東口湧入並排至西口時，水流會因地勢落差，在寬約 20 公尺的圓型豎井口形成巨大的漩渦，順著導水溝落入柚子坑溪。
    - 水量充沛時，甚至會看到水柱從通氣孔噴射出的奇蹟景象。
*   **小瑞士風景**: 周邊環繞著翠綠的林木與果園，營造出寧靜如歐洲小鎮般的雰圍。
*   **山海驛站與集章**:
    - **集章服務**: 山海圳國家綠道官方集章點之一（大圳之路段）。
    - **步道起點**: 這裡是翻越烏山嶺進入曾文水庫前的最後整備站。
