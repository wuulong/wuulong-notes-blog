# MSTW 22 里佳林間步道→里佳部落→賞楓步道

## 路線概況
- **路線分段**：烏奇哈溪溪畔(林間步道南口) → 里佳部落核心 → 賞楓步道出口
- **長度**：山徑 0.52 KM / 產業道路 0.31 KM
- **分級**：2級 (緩坡山徑與部落街道)
- **所需時間**：步行約 40 分鐘 (上坡方向) / 約 30 分鐘 (下坡方向)
- **起訖點**：林間步道入口 / 賞楓步道出口
- **餐飲建議**：[里佳部落](?map=20260202_shanhaijun&feature=20260202_shj_poi_043)內有數間特色民宿與部落餐廳，建議在此停留補給或用餐。
- **周邊景點**：[里佳資訊站](?map=20260202_shanhaijun&feature=20260202_shj_poi_067)、風洞流步道、大樟樹、部落文化牆

## 路線描述
此段路徑帶領旅人踏入阿里山最深處、被譽為「藍色部落」的里佳，體驗純粹的山林靈氣與鄒族神話。

路線始於烏奇哈溪畔的林間步道，沿著整修良好的木棧道蜿蜒而上。沿途穿梭於蒼翠的竹林與參天的大樟樹下，享受芬多精的洗禮。抵達里佳部落後，行經整齊且充滿原民特色的街道，隨手可見部落族人曬愛玉子或製作竹藝的靜謐生活景象。隨後銜接至賞楓步道，鄒族傳說中，天神哈莫搖動楓樹落下的楓實化成了鄒族的祖先，因此這段路徑不僅是風景線，更是溯源祖靈與自然連結的神聖之路。

## 特色與生態
- **藍色部落**：里佳因環境極低汙染，白日天空蔚藍，夜晚星辰璀璨，夜空藍得發亮，故得名。
- **神話楓情**：賞楓步道兩側廣植楓香與青楓。每逢深秋，綠葉轉為金黃與艷紅，漫步其中如入畫境。
- **螢火蟲勝地**：里佳生態極佳，春夏交替之際，步道周邊點點螢光飛舞，是絕佳的生態觀察點。

## 注意事項/建議
- **部落導覽**：里佳部落提供豐富的生態導覽與愛玉DIY體驗，強烈建議預約參與，更能感受「藍色部落」的深度魅力。
- **尊重社區**：在部落街道行走時請保持安靜，未經許可請勿隨意進入居民住宅或拍攝隱私區域。
