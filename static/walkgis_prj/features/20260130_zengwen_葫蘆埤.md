# 葫蘆埤自然公園

## 簡介
因挖掘灌溉埤塘後地形酷似葫蘆而得名，是嘉南大圳灌溉系統中的重要埤塘，現轉型為休閒與生態觀察點。

## 觀察重點
- **埤塘日落**：此處是觀賞曾文溪流域夕陽的絕佳點，吊橋與湖面的倒影極具美感。
- **水利系統**：觀察大圳如何配水至埤塘，再由埤塘調節進入田間，理解早期農業水權社會的運作。
- **菱角產業**：周邊為官田菱角主要產區，埤塘的水分調節是此特產的關鍵。
