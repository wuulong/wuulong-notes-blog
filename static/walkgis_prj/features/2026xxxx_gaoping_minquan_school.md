# 那瑪夏民權國小：鑽石級綠建築

## 📝 景點簡介
融合布農與卡那卡那富家屋意象的高性能建築，更是山區居民遭遇極端氣候時的最後營地。

## 🔍 流域深度解析
1. **部落避難方舟**：
   它是莫拉克災後「離災不離村」的具體成果。由台達電援建，強調能源自主，是南台灣高山流域環境中最具指標性的韌性建築。
2. **探索觀點**：
   造訪此地時，請注意觀察其作為高屏溪「生存過濾系統」或「歷史傷痕」的具體細節。
