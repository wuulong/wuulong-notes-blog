# 那瑪夏民權國小：鑽石級綠建築

![2026xxxx_gaoping_minquan_school](https://upload.wikimedia.org/wikipedia/commons/thumb/4/44/%E6%9D%B1%E8%8F%AF%E9%8C%84%28%E7%8E%8B%E5%85%88%E8%AC%99%29%28%E5%9B%9B%29.djvu/page1-1280px-%E6%9D%B1%E8%8F%AF%E9%8C%84%28%E7%8E%8B%E5%85%88%E8%AC%99%29%28%E5%9B%9B%29.djvu.jpg)


## 📜 歷史與地景背景
舊校舍毀於土石流，由台達電援建。其設計強調能源自主與災難韌性，是高山流域探索的最深意象點。

## 🔍 流域深度解讀
被譽為全台最美的綠建築，更是部落的救命方舟。融合原民家屋意象與高科技能源，是災後重建最成功的典範。

## ✨ 亮點特色
- 鑽石級綠建築
- 部落避難方舟
- 家屋意象傳承
