# 南科考古館 (Nanke Archaeology Museum)

![20260130_zengwen_南科考古館](https://upload.wikimedia.org/wikipedia/commons/thumb/d/d7/ROC_National_Museum_of_Prehistory_Seal.svg/1280px-ROC_National_Museum_of_Prehistory_Seal.svg.png)


## 簡介
國立臺灣史前文化博物館南科考古館，保存了大量因南部科學園區開發而搶救發掘的史前遺址。

## 觀察重點
- **環境變遷紀錄**：館內遺址層位精確紀錄了曾文溪沖積平原在過去五千年來的環境變遷。觀察地層中的淤泥與人類生活殘跡。
- **古河道與聚落**：史前先民如何依水而居，以及曾文溪（或其前身古河流）的改道如何影響了三和、大湖、蔦松等文化的遷移。
- **災難地層**：尋找考古證據中關於特大洪水事件的痕跡，理解「青瞑蛇」在史前時代的威力。
