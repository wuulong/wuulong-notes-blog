# 鄒風館部落餐廳 (Zou Feng Guan Indigenous Restaurant)

![20260202_shj_poi_103](https://lh3.googleusercontent.com/places/ANXAkqFWCLorUdzKjH4FxhaZ7glFyXNnsO29ytFFkxZS3d_MPz-hp0LHnxu9QXvPglR-MZxma7OXjd94S_XI5sxNe61uw9HRqNoIGtI=s1600-w1200)


鄒風館位於阿里山最大的鄒族部落——達邦村，由返鄉青年與其母親共同經營。它是山海圳「原鄉之路」中結合了傳統食材與現代烹調美學的指標性創意餐館。

## 🔍 特色與細節
*   **新鄒式美食**: 將傳統原民餐點（如烤肉、溪魚、野菜）進行視覺與口味上的升級，強調「旬之味」，保留傳統風味的同時也展現了當代料理精緻感。
*   **工藝藝術空間**: 餐廳本身也是一個展現鄒族文化傳統與在地工藝的複合空間。餐具與裝潢中融入了大量部落圖騰，氣氛極佳。
*   **在地溯源**: 嚴選阿里山當季時令農產，確保每一口吃下的都是這片土地最清甜的饋贈。

## 💡 旅人筆記
*   **美味推薦**: 其精緻的拼盤料理是視覺與味蕾的雙重享受。特別是針對山海圳挑戰者，這裡提供了如同「深山米其林」般的能量支持。
*   **預約指南**: 因其在美食部落客與遊客間極具口碑，建議在預計到達時間前的數日先行預訂位子。
*   **文化深度**: 用餐後可與店內經營者聊聊，聽聽他們返鄉推動部落餐飲轉型的初衷與故事。
