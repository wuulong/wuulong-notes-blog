# 國立臺灣歷史博物館 (National Museum of Taiwan History)

## 簡介
座落在昔日台江內海的浮覆地上，這裡不僅是國家級博物館，其地基本身就是一段曾文溪改道史的現場。

## 觀察重點
- **滄海桑田展現**：館內常設展「斯土斯民」提供了最權威的曾文溪改道、台江內海淤塞的地圖與模型，是流域探索的「總論」基地。
- **水雲取樣**：戶外園區的攔沙壩與人工湖，模擬了先民在浮覆地上處理水利的邏輯。
- **地誌學入口**：利用館內的數位典藏，比對百年來的歷史地圖與今日的 WalkGIS 軌跡，理解地景重構的深度。
