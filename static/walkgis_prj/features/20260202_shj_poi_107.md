# 排雲山莊 (Paiyun Lodge)

![20260202_shj_poi_107](https://upload.wikimedia.org/wikipedia/commons/thumb/3/33/Paiyun_Lodge_%28Aerial_Photography%29_2025-03-24_original.jpg/1280px-Paiyun_Lodge_%28Aerial_Photography%29_2025-03-24_original.jpg)


位於海拔 3402 公尺處，是攀登台灣最高峰——玉山主峰最重要的宿營與中繼點。在山海圳國家綠道 177 公里的漫長旅程中，這裡是最後衝刺攻頂前的靈魂堡壘。

## 🔍 特色與細節
*   **高山避風港**: 山莊坐落於玉山主峰西坡下方 2.4 公里處，提供床位、簡易餐廳與基本醫療支援，是登山者在空氣稀薄的高海拔帶最強大的後盾。
*   **聖山認證站**: 抵達排雲山莊，象徵著旅人已克服了絕大部分的垂直上升考驗。從這裡望向主峰，那份神聖感是不言而喻的。
*   **環保與尊重**: 山莊運作極為仰賴協作人員身背重物運送物資與處理廢棄物。旅人在此須落實「無痕山林」(LNT) 精神，共同守護脆弱的高山環境。

## 💡 旅人筆記
*   **中籤即幸運**: 山莊床位一位難求，通常需經過國家公園的抽籤程序。若有幸抽中，請務備齊保暖裝備與高山症藥物。
*   **排雲餐食**: 推薦預約山莊提供的統一供餐服務，在 3400 公尺的高度喝上一碗熱騰騰的湯，是旅途中極致的救贖。
*   **攻頂預備**: 旅人通常會在凌晨由此出發攻頂，請在晚上 8 點熄燈後保持靜謐，尊重他人的休息權利。
