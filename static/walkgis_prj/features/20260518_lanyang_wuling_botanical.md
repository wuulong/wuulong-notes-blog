# 武陵農場植物園

武陵植物園是一處封裝了高海拔溫帶與亞寒帶植物生態的「自然景觀與節氣地貌物件」。

## 🌲 現地考掘與感官經驗
*   **樹木與節氣的視覺預期**：
    散步於植物園的林道間，被各種高聳與形態各異的樹木包圍。實地觀察這些高山林木的樹皮、針葉與樹冠。在不同的節氣（如深秋的楓紅、寒冬的枯枝與初春的櫻花）流轉時，這座植物園將展現出完全不同的生命美感與色彩地質。
*   **水生植物區的距離屏障**：
    植物園內設有水生植物區，展示了高山溪流濕地特有的植物群落。然而在空間配置上，這條路線被設計為「只能遠觀，無法近身跨越」，保持了一種生態保護所需的物理距離屏障。
