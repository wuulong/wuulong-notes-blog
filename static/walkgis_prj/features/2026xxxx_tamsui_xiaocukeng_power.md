# 小粗坑發電廠

## 簡介
小粗坑發電廠（現稱為桂山發電廠粗坑機組）建於明治四十年（1907年），於1909年竣工發電。它位於新店溪屈尺大曲流下游的新店路旁，是**台灣歷史上第二座水力發電廠**。該廠紅磚砌築的古典巴洛克式廠房至今保存完好，更驚人的是，它是**台灣現役最古老、且仍在運轉發電**的水力發電廠，被列為新北市歷史建築。

## 觀察重點
- **巴洛克式紅磚建築**：欣賞發電廠充滿歷史感與美學的紅磚外牆、圓拱窗和排氣窗，是古典工業建築的傑作。
- **粗坑壩與引水引道**：觀察上游的粗坑堰（粗坑壩）如何截引新店溪水，通過長達數百公尺的引水路引入壓力鋼管進行重力發電。
- **百年現役運轉奇蹟**：思考這座歷經百年的水輪發電機組如何持續為大台北電網注入微小但具象徵意義的綠色電能。
