# 四草綠色隧道

![20260201_zengwen_四草綠色隧道](https://upload.wikimedia.org/wikipedia/commons/thumb/3/36/Sihcao_Green_Tunnel.JPG/1280px-Sihcao_Green_Tunnel.JPG)


## 簡介
被譽為「台版亞馬遜河」，是早年台江內海淤積後殘留的人造運河。兩旁密佈紅樹林，展現了河流與潮汐交織的獨特生態。

## 觀察重點
- **紅樹林體系**：觀察五梨跤、水筆仔、欖李、海茄苳等紅樹林如何鞏固濕地。
- **古水路紋理**：身處竹筏上，感受曾文溪輸出的泥沙如何改變當地的航運史。
- **台江殘影**：這裡曾是大員（安平）對岸的重要水域，如今縮減為一條翠綠細流。
