# 山上花園水道博物館 (原台南水道)

## 簡介
此處為日治時期「台南水道」的主體，見證了台灣現代自來水系統之開端。水源取自曾文溪，經過沈澱、過濾與加壓送至台南市。

## 觀察重點
- **快濾筒室**：宏偉的紅磚建築，內建大型濾筒設備。
- **淨水池**：位於斜對面小山頭，具有特殊的藍色大門與石龕。
- **工業美學**：觀察日式建築工藝與工業設施的結合。
