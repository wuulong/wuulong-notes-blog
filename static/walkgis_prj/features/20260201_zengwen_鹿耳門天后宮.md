# 鹿耳門天后宮

## 簡介
坐落於當年曾文溪入海口的歷史座標上，見證了台江內海從汪洋變桑田的完整過程。

## 觀察重點
- **地誌變遷**：理解此地如何從曾經的「鹿耳門港」變成深處內陸的聚落。
- **媽祖信仰與改道**：觀察廟宇與河流改道史的連結，水利與民俗的共生。
