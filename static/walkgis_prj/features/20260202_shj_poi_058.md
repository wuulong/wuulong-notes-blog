# 護照優惠-救國團曾文青年活動中心 (Zengwen Youth Activity Center)

![20260202_shj_poi_058](https://lh3.googleusercontent.com/gps-cs-s/AHVAweoPJaCvwEYFH9jUa--_ugCRrxQMZK1kK1-W_h11hRkycpIRDd78X_ae4YOD8yR6ZA1u8J5V26OagatgfX1uVYKJj9w9nm11CIGbfMMr1qRaf2vTIAHo9Bw4BnQ6f_DEpsYOVPkBBg=s1600-w1200)


位於曾文水庫風景區內，由知名建築師設計，其獨特的船型建築與自然景觀融合，是山海圳「大圳之路」中段的重要集體住宿與補給點。

## 🔍 特色與細節
*   **環保與地景建築**: 建築外觀如同停泊在水岸邊的大船，內部設施完善，包含大型集會廳、交誼空間及多樣化房型。
*   **護照優惠**: 持有山海圳國家綠道集章護照的旅人，在此訂房入住（包含客房與通舖）可享有特定方案折扣。
*   **戶外活動基地**: 園區內設有山野訓練場、攀岩牆與大草皮，是推廣戶外教育與團隊合作的重要基地。

## 💡 旅人筆記
*   **安靜清幽**: 由於位於水庫園區內部，周邊無光害，夜晚可欣賞壯麗星空。
*   **徒步中轉**: 從大埔往西拉雅（或反向）健行的旅人，在此住宿可大幅減少體力損耗。
*   **入園須知**: 進入中心同樣需經過曾文水庫收費站領取入園憑證，住宿旅人可享有特定門票折抵（請於訂房時確認）。
