# 安平開台天后宮

![20260131_zengwen_安平天后宮](https://upload.wikimedia.org/wikipedia/commons/thumb/c/c1/%E5%AE%89%E5%B9%B3%E9%96%8B%E5%8F%B0%E5%A4%A9%E5%90%8E%E5%AE%AE_-_panoramio.jpg/1280px-%E5%AE%89%E5%B9%B3%E9%96%8B%E5%8F%B0%E5%A4%A9%E5%90%8E%E5%AE%AE_-_panoramio.jpg)


## 簡介
這裡是台灣最早的媽祖廟之一，與安平開港歷史緊密相連，展現了台江內海地區深厚的信仰層次。

## 觀察重點
- **夜間美學**：觀察廟宇夜間的燈光設計，展現與白天不同的莊嚴氛圍。
- **多元共祀**：觀察其包羅萬象的祭祀體系，體現漢人移墾台灣的精神包容性。
- **沿海歷史**：雖然位於安平，但其歷史與曾文溪改道、台江內海演變息息相關。
