# 特富野餐廳 (Tefuye Restaurant)

位於阿里山特富野大社內，是一間具備濃厚傳統氛圍的原民特色餐廳，為造訪特富野古道與庫巴 (Kuba) 的旅人提供地道的鄒族美食補給。

## 🔍 特色與細節
*   **深山的原味**: 餐廳以提供「部落平日飲食」與「祭典料理」的轉化版著稱。在這裡可以吃到最道地的木炭烤肉、山產野菜及傳統的小米製品。
*   **地理驛站**: 距離具備歷史意義的特富野神聖會所與古道起點極近，是旅人在進行部落深度遊覽時最佳的歇腳處與能量充填站。
*   **質樸空間**: 環境強調簡單、自然，讓人能心無旁騖地沈浸在山林的美食中。

## 💡 旅人筆記
*   **必嚐推薦**: 特富野當地的竹筍料理非常有名，此外山產拼盤也是補充蛋白質的絕佳選擇。
*   **文化尊重**: 餐廳位於大社核心區，進入部落前請先了解其禁忌規則，用餐時也可感受部落內那種平靜且肅穆的氛圍。
*   **營業確認**: 由於山區偏遠，建議出發前先行確認營業狀態或提前預訂，以免撲空。
