# 東眼山國家森林遊樂區

## 簡介
東眼山國家森林遊樂區位於桃園市復興區，因東眼山山形神似「大眼睛向東眺望」而得名。園區屬於大漢溪水系支流霞雲溪與大豹溪的源頭分水嶺區域。東眼山保存了大量日治時期保留至今的林業文化遺跡，同時擁有非常豐富的生代地層化石與波痕地質遺跡。

## 觀察重點
- **地質歷史（生痕化石與波痕）**：在步道旁觀察約三千萬年前「木山層」沉積岩上的生痕化石（古代生物活動遺留的管道跡）與波痕地表，這是此處曾為淺海河口沙灘的鐵證。
- **林業文化史**：觀察園區內保留的集材機（蹦蹦車車道、索道）、培育柳杉林與人工林林相，了解北部山林在日治與戰後時期的林業開採與復育史。
- **霞雲溪源頭**：感受分水嶺山林地帶，理解東眼山作為大漢溪與三峽河上游集水區的林相保護價值。
