# 山海驛站-東口工作站 (East Outlet Station)

東口工作站位於台南市楠西區，是嘉南平原生命線——嘉南大圳水利系統中的核心節點。這裡也是知名的「烏山嶺水利古道」終點，承載著八田與一團隊開發大圳的艱辛歷史。

## 🔍 特色與細節
*   **引水發電樞紐**: 東口是曾文水庫水源輸送至烏山頭水庫的關鍵出口。日治時期稱為「曾文溪取入口詰所」，負責監控與操作水源引入口的運作。
*   **水利古道歷史**: 烏山嶺水利古道最初是為了興建引水隧道（舊隧道）而闢建的物資運輸與勘查動線。東口一帶保留了早期水利建設的官舍遺蹟與相關紀念指標。
*   **改制沿革**: 從早期的農田水利會，於 2023 年改隸為「農業部農田水利署嘉南管理處」，持續守護著嘉南平原的灌溉命脈。

## 💡 旅人筆記
*   **山海驛站功能**: 為徒步或騎行「大圳之路」的旅人提供關鍵的地理與水利知識教育空間。
*   **古道挑戰**: 若您計畫行走烏山嶺水利古道，東口是重要的出入口。行前請務必確認步道狀況與個人體力。
*   **景緻與氛圍**: 這裡有著公務機關的靜謐與肅穆，旅人造訪時請遵守相關規範，切勿干擾水利設備的運轉。
