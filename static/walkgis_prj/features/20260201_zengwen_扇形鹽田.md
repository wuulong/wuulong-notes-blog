# 青鯤鯓扇形鹽田

## 簡介
這是台灣唯一的扇形鹽田，展現了 1970 年代精密的鹽工技術。其放射狀的給排水導溝設計，是人類管理海水的極致視覺化成果。

## 觀察重點
- **幾何給水系統**：觀察鹽田如何透過放射狀條紋控制水流，將海水引入各個結晶池。
- **曾文溪流域末梢**：這裡位於曾文溪與將軍溪之間，是河流沉積物與海洋博弈出的土地。
- **生命之扇**：理解這片土地從汪洋到鹽灘、再到目前生態棲地的多重轉身。
