# 八田與一紀念園區

![20260131_zengwen_八田與一紀念園區](https://upload.wikimedia.org/wikipedia/commons/thumb/8/8c/Yoichi_Hatta%27s_statue_and_tomb-P1010493.JPG/1280px-Yoichi_Hatta%27s_statue_and_tomb-P1010493.JPG)


## 簡介
為了紀念嘉南大圳之父八田與一而修复的日式建築群，包含其故居。

## 觀察重點
- **日式宿舍建築**：觀察木構建築的修復工法與庭園設計。
- **圳路圖研究**：園區內展示的嘉南大圳詳細圳路圖，是理解這套龐大水利循環系統的鑰匙。
- **天壇模型**：觀察園區內的天壇模型與建築歷史。
