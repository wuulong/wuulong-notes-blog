# 虎頭埤風景區 (Hutoupi - First Reservoir in Taiwan)

## 簡介
雖行政區域上與曾文溪主流有別（屬鹽水溪水系），但虎頭埤作為 1846 年完工、全台第一座灌溉水庫，是理解曾文溪中下游水利調節、漢人先民在大地築堤攔水的最佳歷史對照。

## 觀察重點
- **百年堤防**：觀察歷經170餘年的土堤，理解跨時代的水利補強工法。
- **調節邏輯**：思考曾文溪大規模工程出現前，區域性小水庫如何支撐起台南平原的初期農業興盛。
- **休閒轉向**：從純粹的水利設施轉化為近代風景區的空間功能演變。
