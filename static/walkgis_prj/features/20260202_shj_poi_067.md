# 住-Mimiyo 秘密遊民宿 (Mimiyo B&B)

![20260202_shj_poi_067](https://lh3.googleusercontent.com/places/ANXAkqFR8anGlLG5H5J6soPnU2RE9ZhDYVo2lbm-7fgVkl8iGQ-wMQPMldXvBZvIWE761ihtGdh1aSyMMzuE8wFDjzgk3N4YaFKsbH8=s1600-w512)


位於嘉義縣阿里山鄉達邦部落，海拔約 1400 公尺。「Mimiyo」在鄒語中意為「趴趴走」，象徵著在大自然中隨心漫遊的生活態度。

## 🔍 特色與細節
*   **深山秘境**: 民宿周圍群山環繞，環境極其寧靜，是山海圳「原鄉之路」中最具部落原始美學的下榻點之一。
*   **環保永續**: 提倡綠色旅遊，不提供一次性盥洗用品。民宿使用純淨的山泉水，並提供絕佳的面山景陽台。
*   **深度文化體驗**: 民宿主人具備專業解說資格，可帶領旅人進行部落文化與生態深度巡禮。

## 💡 旅人筆記
*   **圍爐聽故事**: 若有機會，別錯過與老闆在火塘前喝茶、聽他彈吉他講述部落傳說的時光。
*   **補給提醒**: 達邦地區購物較不便，建議進入前備妥個人常用物品。
*   **部落晚餐**: 強烈推薦預約其部落風味晚餐，體驗道地的原民烹調智慧。
