# 台灣櫻花鉤吻鮭生態中心 (Taiwan Landlocked Salmon Center)

## 📌 空間屬性
- **座標**：24.3541788, 121.3128508
- **類型**：生態保育中心 / 生物地景

## 📜 OO-History 考掘
- **【冰河孑遺生物物件】**：櫻花鉤吻鮭作為台灣特有的冰河孑遺魚類，因大甲溪上游（七家灣溪）冷涼、清澈、未受污染的水溫環境，成為牠們在熱帶島嶼高海拔區域殘存的唯一棲地。
- **【現地觀察】**：雖然抵達時間較晚錯過開館時間，但生態中心門口的戶外展示池中，依然能清晰觀察到活生生的國寶魚游動，將課本上的冰河歷史直接帶入眼簾。
