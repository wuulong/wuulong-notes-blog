# 護照販售｜優惠-嘉娜百藝工坊 (Ganabai Art Workshop)

![20260202_shj_poi_049](https://lh3.googleusercontent.com/places/ANXAkqGyMQnnAeMUdRZSrZpOtiKM61EnMgvS-rUcjFSnbgkqF8spGektNuSeL78PtoOGdNTYxR8AwaiHNEyPyR6CPxukkHi7zFV0uQ=s1600-w1200)


嘉娜百藝工坊位於嘉義縣阿里山鄉里佳部落，「百藝」在鄒族語中意為「阿嬤」，象徵著文化的傳承與原始手藝。

## 🔍 特色與細節
*   **藍色部落文化節點**: 里佳部落以湛藍星空與清澈天空聞名。工坊致力於推廣在地天然農產加工與傳統工藝。
*   **護照優惠**: 持山海圳集章護照入內，購買特定飲品（如部落咖啡、愛玉）或精選農產品，可享 85 折優惠。
*   **手作體驗**: 提供洗愛玉、咖啡烘焙體驗，讓旅人深刻體會「全台最深山部落」的慢活美學。

## 💡 旅人筆記
*   **原鄉補給**: 這裡是山海圳「原鄉之路」極為偏遠但溫暖的補給點，建議在此多與當地族人互動，能獲得地圖以外的感人故事。
*   **必試美食**: 里佳產的愛玉籽品質冠絕全台，洗出的愛玉口感Q彈細緻。
*   **山野氣候**: 里佳海拔約 1000-1400 公尺，早晚溫差大且常有霧。
