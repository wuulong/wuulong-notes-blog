# 溪頂寮保安宮 (Baosing Temple, Xidingliao)

![20260202_shj_poi_010](https://lh3.googleusercontent.com/gps-cs-s/AHVAweoNyqoVjT_k1G1UociIISZp1-Ro0lZj9T_f3xOrEC1bi5gtkNiVL2ciQxUV3zVlMVJzNAd85_fn4sVgPA3ALq9U2zT_1CAKPU0DF7K6BK315bkOb3H3NkanfqRPnZWq9y3WbqC42n8VpEc_=s1600-w1200)


溪頂寮保安宮位於台南市安南區，主祀保生大帝。這裡是古台江時期曾文溪改道堆積出的海埔新生聚落，保安宮自古以來便是溪頂寮庄頭的守護中心。

## 📜 歷史背景 (Historical Context)
*   **聚落起源**: 溪頂寮於古台江內海時期曾是重要港埠。清咸豐年間，地方總理徐群捐出土地，居民搭蓋茅寮作為公厝，供奉分靈自學甲慈濟宮的保生大帝，兼具私塾學堂功能。
*   **重建歷程**: 廟宇曾多次遷址重建，現址磚造建築於 1923 年重新遷回落成，於 1975 年再次擴建為現貌。
*   **界址廟合祀**: 廟內亦合祀了原址鄰近舊「界址廟」的護國元帥與李姑娘，展現了地方基層信仰的族群融合。

## ✨ 亮點特色 (Highlights & Features)
*   **送火王科儀**: 保有百年的市定民俗「送火王」（三年一科）。此儀式源於早期聚落皆為草寮易生火災，透過宋江陣巡庄、熄燈禁聲送火王至鹽水溪，祈求庄頭平安。
*   **山海驛站服務**: 這裡是山海圳國家綠道「內海之路」的重要服務節點。
    - **服務設施**: 提供集章服務、洗手間與補水休憩空間。
*   **精美工藝**: 廟宇內的石雕、剪黏展現了南台灣傳統建築藝術之美。
