# 蘭陽溪口水鳥保護區

位於蘭陽溪、宜蘭河與冬山河三水匯流處的蘭陽溪口，是全流域縱走計畫中「大河入海與生態屏障終點物件」。

## 🌾 現地考掘與感官經驗
*   **非冬候鳥季的荒涼對位**：
    傍晚時分抵達河口，此時為五月中旬，並非冬候鳥遷移的巔峰期，因此寬廣的板岩沙洲上一隻水鳥也沒有看到。這體現了生態地景強烈的「季節性不對稱」。
*   **海邊無人小路的移動身體感**：
    為了尋找海岸沙丘與防風林的邊界，開車在幾乎沒有任何人烟、路面長滿雜草的海邊窄小便道上緩慢移動。海風強烈地吹拂著車身，被荒野、廢棄防空碉堡與翻滾海浪夾道的孤獨移動感，為這趟長途河流大縱走劃下了極具厚重感的終點句點。
