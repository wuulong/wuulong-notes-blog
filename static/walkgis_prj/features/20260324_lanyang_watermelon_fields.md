# 蘭陽溪河床西瓜地景

## 🌟 亮點描述
蘭陽溪以含砂量高聞名，枯水期時露出的廣大砂質河床，成為孕育「蘭陽甜西瓜」的最佳溫床。這種隨季節變動的農業生產，形成了台灣獨特的河流地景。

## 📜 歷史背景與深度知識
根據《蘭陽溪流域深度研究計畫》，此點位具有以下核心價值：
- **地質決定論 (Economic Geology)**：西瓜根系極度厭氧。蘭陽溪河床的砂礫土（Gravel and Sand）孔隙率高、排水極快，為西瓜提供了理想環境。
- **熱量調節**：砂石比熱小，日夜溫差大，有利於果實糖分累積。
- **治理博弈**：農民種植低莖作物可抑制河床揚塵（風飛沙），同時不阻礙洪水流動，達成「河防安全、抑制揚塵、農民生計」的三贏局面。
