# 二仁溪綠堤：堤防上的再生藝術

位於二層行橋附近的綠堤廊道，透過馬賽克拼貼呈現地方文化與自然生態，是「水環境改善計畫」的視覺縮影。

## 📜 歷史背景
為了洗刷二仁溪「黑龍江」的污名，水利署在整治堤防的同時，引入了公共藝術。這些馬賽克牆不僅美化了剛硬的防洪牆，更融入了關於河流重生、漁民生活與生態多樣性的敘事。

## ✨ 亮點特色
- 堤頂馬賽克公共藝術
- 親水步道與休憩涼亭
- 污染整治成果的視覺展示
- 座標：22.9146, 120.2250
