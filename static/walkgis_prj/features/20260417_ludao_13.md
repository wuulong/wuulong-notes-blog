# 柚子湖彎弓洞

全綠島最大的天然海蝕拱門，展現了太平洋波浪對火山岩層強大的「穿孔」能力。

## 📜 歷史背景 (Historical Context)
洞穴呈完美的放射狀展開，因其跨度巨大故有「彎弓」之名。這裡曾是史前人類與早期漢人移民避暑、躲避風災的天然庇護所，現在則是觀察綠島大尺度海蝕地貌動態的最佳點位。

## ✨ 亮點特色 (Highlights & Features)
- **藍色之窗**: 在洞內向外望去，天空與海洋被火山岩邊界框成一幅完美的畫作。
- **垂直解理面**: 觀察支撐拱門的安山岩基柱，其承受波浪打擊產生的裂痕。
