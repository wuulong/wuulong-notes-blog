# 種書店｜拔林賴氏七房宗祠 (Seed Bookstore)

位於官田拔林車站旁的慈安宮斜對面，種書店是由國立臺南藝術大學師生共同打造的在地實踐空間。它將古老的「拔林賴氏七房宗祠（拔林工作站）」部分空間活化，以書本為種子，栽種對土地的關懷，成為收藏曾文溪流域記憶的時光寶盒。

## 🔍 特色與細節
*   **流域知識寶庫**: 書店主要蒐集關於曾文溪流域、官田地區的歷史、文化、生態與美食資訊。這裡不僅是一間書店，更是一個地區文獻的展示與閱讀空間。
*   **宗祠與現代的交織**: 店址所在的賴氏宗祠（拔林工作站）展現了民國 50 年代在地家族的顯赫歷史。南藝大師生透過「無支配藝術實踐」課程，自主修繕空間、募集書籍，將其轉型為當地的藝文燈塔。
*   **在地認同據點**: 種書店不僅吸引外地旅人，更提供在地居民一個談天、回味流域往事的場所，實踐了「地方創生」的深層意涵。

## 💡 旅人筆記
*   **流域必讀**: 徒步山海圳綠道的旅人若經過拔林，非常推薦在此駐足，透過店內的書籍更深入了解腳下這片土地的脈絡。
*   **步行可達**: 距離拔林火車站僅約 3 分鐘路程，是山海圳「大圳之路」段落中極具溫度的中繼站。
*   **開放資訊**: 因由大學師生營運，建議造訪前先查詢其官方社群（如 Facebook）確認當日是否開館。

- **鄰近交通**: 拔林火車站 (步行 3 分鐘)
