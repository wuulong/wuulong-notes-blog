# 護照販售-森 2488m X 馬羊家茶 (Sen 2488m X Mayoungtea)

![20260202_shj_poi_050](https://upload.wikimedia.org/wikipedia/commons/thumb/a/ad/%E6%B2%BB%E8%87%BA%E5%BF%85%E5%91%8A%E9%8C%84%28%E4%BA%8C%29.djvu/page1-1280px-%E6%B2%BB%E8%87%BA%E5%BF%85%E5%91%8A%E9%8C%84%28%E4%BA%8C%29.djvu.jpg)


位於阿里山轉運站 3 樓，這是一間充滿森林氣息與文創能量的高山咖啡廳，也是山海圳綠道中極具美學深度的服務節點。

## 🔍 特色與細節
*   **森林系觀景空間**: 店名「2488m」象徵著對於高海拔自然環境的嚮往。大面窗戶正對阿里山山脈，雲霧繚繞時仿若置身仙境。
*   **文創與林業結合**: 這裡也是林務局「森 2488m」品牌的展示點，陳列了結合林務文化與當代設計的木製藝品與生活好物。
*   **護照據點**: 提供山海圳國家綠道實體護照販售與旅遊諮詢。
*   **茶與咖啡的對話**: 選用阿里山高山茶與手沖咖啡。

## 💡 旅人筆記
*   **登山整備**: 這裡提供舒適的座位與無線網路，適合旅人在進入森林遊樂區登山前，進行最後的數位地圖檢核與行程確認。
*   **獨家選物**: 推薦選購具地方設計感的木質公仔或紀念品，支持在地文創經濟。
*   **開放時間**: 每日 09:00 - 17:00 (以現場公告為準)。
