# 左鎮化石園區 (菜寮溪惡地)

## 簡介
左鎮化石園區是台灣唯一的化石主題博物館，位於曾文溪支流菜寮溪旁。菜寮溪常因暴雨沖刷出化石，包括著名的早坂犀牛。

## 觀察重點
- **惡地地形**：觀察菜寮溪沖刷出的泥岩地形。
- **化石資源**：犀牛、猛瑪象等多樣性的第四紀脊椎動物化石。
- **古地理演變**：了解該地從海洋、河口到陸地的環境變遷。
