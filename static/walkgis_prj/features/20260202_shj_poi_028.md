# 山海驛站-茄拔工作站 (Qieba Irrigation Station)

茄拔工作站位於台南市善化區，隸屬於農田水利署嘉南管理處。它是嘉南大圳南幹線末端的重要調節點，負責管控輸送至善化、官田一帶農田的灌溉水源。

## 🔍 特色與細節
*   **大圳南端據點**: 歷史可追溯至 1930 年設立的「嘉南幹線監視所」。在嘉南大圳複雜的供水網絡中，茄拔站確保了南幹線水源能精準分配至各支線與分線。
*   **灌溉命脈守護**: 轄區內管理著數千公尺的水路，是確保善化地區豐富農產（如草莓、胡麻）得以穩定供水的幕後英雄。
*   **組織演變**: 2023 年配合行政院組織升格，正式改制為「農業部農田水利署嘉南管理處烏山頭分處茄拔工作站」，展現了現代化水利管理的新風貌。

## 💡 旅人筆記
*   **文化節點**: 綠道行經茄拔地區時，除了造訪知名的茄拔天后宮，不妨也觀察周邊縱橫交錯的大圳水路，感受這套運行近百年的水利工程。
*   **驛站補給**: 提供基礎的空間指引服務，是理解在地農業景觀與水利運作的最佳觀察點。
*   **周邊農產**: 茄拔站守護的灌溉區正是善化著名的草莓產區，產季造訪時可一併體驗採果樂趣。
