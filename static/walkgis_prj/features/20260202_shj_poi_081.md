# 住-給巴娜民宿 (Keupana B&B)

位於嘉義縣阿里山鄉達邦部落，「Keupana」是當地的鄒族語地名，民宿坐落於保留原始風貌的鄒族大社聚落中。

## 🔍 特色與細節
*   **生態環抱**: 民宿周邊設有完善的賞鳥、原始林及漁獵生態步道。民宿範圍內即是大自然的延伸，春季更有粉嫩櫻花盛開。
*   **原民大社氛圍**: 與現代化的度假村不同，這裡提供了真實的部落生活節奏，讓旅人能沈浸在非人工化的山林美景中。
*   **設施配套**: 提供餐飲服務與多樣化的導覽行程，房型包含適合家庭或團體入住的三人及四人房。

## 💡 旅人筆記
*   **深度健行**: 推薦以此為基地，由民宿主人帶領或指引，探索周邊如神話般的原始森林步道。
*   **族人熱情**: 這裡提供的部落風味餐飲能量充沛，是山海圳「原鄉之路」極受好評的體能充填點。
*   **交通提醒**: 沿 169 縣道抵達達邦村後，建議先至部落中心聯繫民宿確認最後一段路程。
