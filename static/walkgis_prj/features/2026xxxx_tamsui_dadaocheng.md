# 大稻埕碼頭與水門

## 簡介
這裡是淡水河最具歷史意義的碼頭之一，清末至日治時期是北台灣重要的貿易集散地。現今除了是藍色公路的據點，也是台北著名的河濱休憩區。

## 觀察重點
- **五號水門 (大稻埕門)**：觀察巨大的防洪閘門設計，了解台北城如何應對淡水河漲潮與暴雨。
- **遺址與解說**：碼頭邊的商貿歷史遺跡解說牌。
- **河濱自行車道**：淡水河右岸的交通樞紐。
