# 山海驛站-東埔山莊 (Tungpu Lodge)

![20260202_shj_poi_026](https://lh3.googleusercontent.com/gps-cs-s/AHVAweqaIDSk5X1Gvt-bsnSgKblC7C6ZB5lmxQxdyMFKsbJGTNddrQ8FPFeVJ00HKLGr0ifbtVjaWHrMaaGFwNsRW787OkgQFCkMreAjVUs1kn2VnbYez22jHt4DJl45amBWFfe9OGAqGw=s1600-w1200)


東埔山莊位於海拔 2,580 公尺處，是攀登玉山主峰最重要的前哨補給站。在山海圳國家綠道「聖山之路」的最後階段，這裡為完成長途跋涉、準備登頂的旅人提供了關鍵的住宿與高度適應空間。

## 🔍 特色與細節
*   **登山前哨站**: 提供簡便的通鋪床位與熱水沐浴，是登山客進行高度適應與整備行李的首選。
*   **聖山之路終章**: 作為山海驛站，它見證了旅人從海拔 0 公尺一路向上至玉山群峰的壯志。
*   **自然生態景觀**: 周邊常有高山鳥類出現，清晨與黃昏時分可眺望雲海與其後的群山環抱，氣氛寧靜肅穆。

## 💡 旅人筆記
*   **預約制服務**: 由於床位有限，必須提前透過網路系統預約。
*   **高度適應**: 建議在此停留一晚進行高度適應，以降低後續前往排雲山莊或登頂時發生高山症的風險。
*   **整備提醒**: 山莊僅供簡易住宿，旅人需自備餐飲或確認供餐時段。
