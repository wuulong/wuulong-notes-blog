# 武陵雪山登山口

位於海拔約 2,000 公尺的雪山大水池登山口，是高山防禦、登山探險與雪山山脈「實體神聖邊界物件」。

## 🏔️ 現地考掘與感官經驗
*   **登山口過乾癮與大水池倒影**：
    作為攀登台灣第二高峰雪山（次高山）的主登山口，這裡劃分了「人類墾殖區」與「荒野大山」的實體分界。雖然因為時間與體力限制未能真正爬上大山，但站在大水池前，看著木屋與清澈天空完美倒影在水池平靜的鏡面中，那便是重工業與河流文明在極限邊界的一場視覺交感。
*   **太早抵達的營業屏障**：
    清晨抵達登山口，服務站尚未營業，因此無緣享用此處著名的「雪山限定冰淇淋」。這也是一場因為時間因素導致的實體「服務不可得」Heuristics。
*   **河流源頭**：
    此處的流路直接匯入七家灣溪，是蘭陽溪上游大分水嶺脊梁的源頭守護者。
