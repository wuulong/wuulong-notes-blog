# 五股獅子頭隘口遺址

## 簡介
五股獅子頭隘口位於淡水河與基隆河匯流處的下游窄口。此處原本是兩岸山脈（左岸觀音山與右岸大屯山系關渡山）逼近河道所形成的天然瓶頸。民國五十三年（1964年），政府為解決台北盆地淹水問題，執行「大台北地區防洪計畫」，將獅子頭隘口炸寬拓建。然而，這項工程炸毀了天然石壁屏障，導致海水倒灌、五股與蘆洲農田鹽化，成為大台北防洪史與環境變遷上極具反思意義的歷史地景。

## 觀察重點
- **隘口原址水文觀察**：觀察基隆河與淡水河匯合後，河道在此處收窄的物理流態，並想像昔日「關渡分潮」兩河會流時的壯觀水花。
- **海水倒灌與地質演變**：理解炸毀隘口後，漲潮時海水順著淡水河長驅直入台北盆地、導致蘆洲/五股低窪地區常年鹽化與水患的物理過程。
- **防洪工程反思點**：對照獅子頭隘口炸毀遺址與附近的二重疏洪道，思索「工程防洪」與「自然地誌」之間的角力關係。
