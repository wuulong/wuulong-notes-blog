# 葫蘆堵大橋

## 簡介
橫跨蘭陽溪中游，是觀察「編織狀河道」與廣大河床農業的最佳制高點。

## 觀察重點
- **編織狀河道 (Braided River)**：蘭陽溪在此段水流散亂、沙洲交錯。觀察不同季節水流切換的路徑。
- **全景展望**：可在此清楚看見蘭陽溪源頭的山區與其流向太平洋的開闊感。
- **防洪工程**：觀察兩側的高大堤防與丁壩，了解如何引導主流以保護兩岸蔥田。
