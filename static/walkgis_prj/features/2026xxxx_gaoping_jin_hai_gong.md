# 新園進海宮：水仙尊王信仰

## 📝 景點簡介
主祀水仙尊王（大禹），是高屏溪出海口左岸的重要信仰中心。對於長期面臨洪泛威脅的居民而言，供奉治水英雄是尋求心理安全感的集體投射。

## 🔍 流域深度解析
1. **鎮水防線**：
   位於出海口感潮帶，是觀察「防禦性水文」與信仰結合的最佳點位。祭祀圈涵蓋鹽埔村、共和村，顯示信仰與河口生計的高度重疊。
2. **探索觀點**：
   造訪此地時，請注意觀察其作為高屏溪「生存過濾系統」或「歷史傷痕」的具體細節。
