# 新園進海宮：水仙尊王信仰

![2026xxxx_gaoping_jin_hai_gong](https://upload.wikimedia.org/wikipedia/commons/thumb/5/55/%E6%96%B0%E5%AE%9A%E4%B9%9D%E5%AE%AE%E5%A4%A7%E6%88%90%E5%8D%97%E5%8C%97%E8%A9%9E%E5%AE%AE%E8%AD%9C%28%E5%85%AD%29.djvu/page1-1280px-%E6%96%B0%E5%AE%9A%E4%B9%9D%E5%AE%AE%E5%A4%A7%E6%88%90%E5%8D%97%E5%8C%97%E8%A9%9E%E5%AE%AE%E8%AD%9C%28%E5%85%AD%29.djvu.jpg)


## 📜 歷史與地景背景
位於出海口感潮帶，與林園鳳芸宮隔河相望。祭祀圈涵蓋鹽埔村、共和村，顯示信仰與河口生計的高度重疊。

## 🔍 流域深度解讀
主祀水仙尊王（大禹），是高屏溪出海口左岸的重要信仰中心。對於長期面臨洪泛威脅的居民而言，供奉治水英雄是尋求心理安全感的集體投射。

## ✨ 亮點特色
- 水仙尊王信仰
- 河口沖積防線
- 鎮水英雄大禹
