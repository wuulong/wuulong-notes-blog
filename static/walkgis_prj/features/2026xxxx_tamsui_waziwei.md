# 挖子尾自然保留區

## 簡介
挖子尾自然保留區位於新北市八里區，坐落於淡水河口的左岸。此處因地形彎曲，潮水在此形成「挖子」大河灣而得名。保留區內由大片水筆仔攔截淡水河泥沙，形成典型且珍貴的河口沼澤生態系。

## 觀察重點
- **潮間帶與河口生態**：觀察水筆仔純林及其伴生的底棲生物，包含多種招潮蟹（如清白招潮蟹、網紋招潮蟹）、彈塗魚以及豐富的鳥類資源。
- **水物理沖淤變化**：觀察漲落潮時，淡水與海水在河口交互作用所帶來的淤積與灘地暴露過程。
- **漁業文史遺產**：觀察岸邊停泊的小型舢舨船，感受清代八里坌港早期作為對外貿易港口的歷史殘跡。
