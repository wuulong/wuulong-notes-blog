# 新化武德殿 (Xinhua Bushido Hall)

![20260130_zengwen_新化武德殿](https://upload.wikimedia.org/wikipedia/commons/thumb/9/9b/2021%E5%B9%B4%E6%96%B0%E5%8C%96%E6%AD%A6%E5%BE%B7%E6%AE%BF.jpg/1280px-2021%E5%B9%B4%E6%96%B0%E5%8C%96%E6%AD%A6%E5%BE%B7%E6%AE%BF.jpg)


## 簡介
日治時期興建的演武場，用於警察及青年修練柔道與劍道。是新化老街及大目降文化園區的重要地標。

## 觀察重點
- **建築結構**：觀察其獨特的「彈簧地板」，這是為了減少練武者受傷而設計的巧妙結構，在全台武德殿中極具特色。
- **文化匯聚**：位於新化核心地段，周邊結合了警察宿舍群與地方老店，展現日治時期聚落規劃的嚴謹空間感。
- **地方生活**：周邊的新化老攤紅豆餅、古早味番薯糖，是融入在地生活的最佳切點。
