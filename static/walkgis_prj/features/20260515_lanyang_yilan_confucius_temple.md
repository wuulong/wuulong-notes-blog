# 宜蘭孔子廟 (Yilan Confucius Temple)

## 📌 空間屬性
- **座標**：24.7628853, 121.7560725
- **行政區**：宜蘭縣宜蘭市（昔稱五圍）
- **類型**：國定/縣定古蹟

## 📜 OO-History 考掘
- **【文化秩序】**：孔廟的建立標誌著蘭陽溪流域從「武裝拓墾」進入「文治社會」。
- **【規訓空間】**：透過萬仞宮牆、櫺星門等空間配置，建立起儒家體制的嚴謹序列，是官府在五圍城內建立意識形態權威的重要節點。

## 📸 現場觀察筆記 (2026-05-15)
- 宜蘭孔廟在多次修繕後，仍保有其莊嚴的空間感。
- 與周邊的光復國小、宜蘭設治紀念館共同構成了五圍的核心文教地帶。
