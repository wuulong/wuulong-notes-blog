# 新化護安宮

![20260130_zengwen_新化護安宮](https://upload.wikimedia.org/wikipedia/commons/thumb/f/f5/%E6%96%B0%E5%8C%96%E5%A4%A9%E5%A3%87%E8%AD%B7%E5%AE%89%E5%AE%AE.jpg/1280px-%E6%96%B0%E5%8C%96%E5%A4%A9%E5%A3%87%E8%AD%B7%E5%AE%89%E5%AE%AE.jpg)


## 簡介
供奉天上聖母，與新化老街緊密相連，是當地重要的守護神。

## 觀察重點
- **媽祖信仰與地理**：雖然新化不靠海，但媽祖信仰在台南水系網絡中無處不在。觀察護安宮如何成為新化商圈發展的精神支柱。
- **廟埕文化**：護安宮的廟埕是早期地方集會的重要場所，可用以想像新化作為曾文溪物資轉運站的繁華。
