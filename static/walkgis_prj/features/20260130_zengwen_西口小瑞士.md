# 西口小瑞士 (Xikou Little Switzerland)

## 簡介
這裡是曾文水庫與烏山頭水庫連動系統的關鍵節點。曾文溪水經由東口導水隧道穿過烏山嶺後，在此處「西口」湧出。

## 觀察重點
- **天井漩渦**：觀測巨大的豎軸溢流井（天井），此設施在海拔較低時會形成壯觀的漩渦，是為了將水導入下方的發電廠與烏山頭水庫。
- **技術意志**：理解人類如何在大山之中開鑿隧道，強行改變河流流向以支撐嘉南平原的灌溉。
- **風景轉向**：此處因水利工程意外造就了如歐洲鄉間的湖光山色，展現了「工程美學」與自然的融合。
