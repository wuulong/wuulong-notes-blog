# 關渡宮與紅樹林區

## 簡介
關渡宮與關渡濕地位於基隆河匯入淡水河的轉角交匯處。關渡宮是北台灣歷史最悠久的媽祖廟之一，見證了早期的河運商貿與河海防禦。其前方的關渡濕地與紅樹林保護區，是淡水河感潮段最珍貴的生態廊道與水鳥棲地。

## 觀察重點
- **感潮段的潮汐變化**：觀察關渡大橋附近，淡水河與基隆河交匯處在乾潮與滿潮時水位與水流方向的顯著改變。
- **關渡宮地理位址與媽祖石**：觀察宮廟背山面河的「獅象守口」風水格局（獅子頭與象鼻），以及廟宇附近的早期媽祖石刻。
- **紅樹林濕地與生態**：沿著關渡自然公園步道觀察大片水筆仔紅樹林、招潮蟹、彈塗魚及過境水鳥，理解感潮河段的生態多樣性。
