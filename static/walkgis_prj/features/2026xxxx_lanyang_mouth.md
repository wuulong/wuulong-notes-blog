# 蘭陽溪口水鳥保護區

## 簡介
這裡是蘭陽溪、冬山河、宜蘭河三條河流匯入太平洋的出海口。由於擁有大片沙洲與豐富的有機物，成為國際級的候鳥遷徙中繼站。

## 觀察重點
- **三河匯流**：觀察不同水系匯合處的沙洲形狀與植被變化。
- **候鳥觀察**：秋冬季可見黑面琵鷺、雁鴨科、鷸鴴科等。
- **海岸變遷**：觀察蘭陽平原海岸線受太平洋強風大浪侵蝕的情況。
