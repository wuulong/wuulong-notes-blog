# 井仔腳瓦盤鹽田

![20260201_zengwen_井仔腳瓦盤鹽田](https://upload.wikimedia.org/wikipedia/commons/thumb/a/a9/%E4%BA%95%E4%BB%94%E8%85%B3%E7%93%A6%E7%9B%A4%E9%B9%BD%E7%94%B0.JPG/1280px-%E4%BA%95%E4%BB%94%E8%85%B3%E7%93%A6%E7%9B%A4%E9%B9%BD%E7%94%B0.JPG)


## 簡介
這是北門地區最古老的鹽田。瓦盤設計是將破裂的瓦片鋪在池底，讓鹽粒結晶更潔白且易於收集。

## 觀察重點
- **瓦盤結晶**：觀察池底瓦片的排列，理解其熱傳導與防止泥土滲入的功能。
- **夕照地景**：這裡是曾文溪以北、鹽分地帶最重要的地誌景點，夕陽與鹽堆倒影構成完整的流域美學。
- **海洋水利**：與上游的水庫供水相對照，這裡展現了另一套利用太陽、潮汐與風力的水能管理。
