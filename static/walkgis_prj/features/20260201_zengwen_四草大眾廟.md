# 四草大眾廟

## 簡介
主祀鎮海大元帥，與四草地區的地理與軍事歷史息息相關，緊鄰知名的四草綠色隧道。

## 觀察重點
- **鎮海傳奇**：了解其與林爽文事件、鴉片戰爭等歷史事件的連結。
- **沿海門戶**：觀察其作為早期台江內海出入門戶的地理意義。
- **古墓遺址**：廟後的海靈佳城（荷蘭人塚），紀錄了台江地區的歷史交鋒。
