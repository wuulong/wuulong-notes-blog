# 鳩之澤溫泉 (Jiuzhize Thermal)

- **座標**：24.5453779, 121.5081831
- **海拔**：約 520 公尺
- **類型**：溫泉 / 地熱景觀

## 📜 OO-History 考掘
- **【熱能物件】**：此處位於多望溪谷，強烈的溫泉湧出顯示了蘭陽溪流域活躍的地質能量。
- **【轉換地景】**：從林場採伐的重工業秩序，轉化為現代的觀光與療癒秩序。煮蛋池的煙霧是地表下巨大熱能的視覺標籤。
