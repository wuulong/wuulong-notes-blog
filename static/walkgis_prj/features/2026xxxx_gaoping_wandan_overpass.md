# 萬丹圳水走天橋：架空導水設施

![2026xxxx_gaoping_wandan_overpass](https://upload.wikimedia.org/wikipedia/commons/thumb/2/27/%E7%99%BE%E4%B8%80%E5%B1%B1%E6%88%BF%E8%A9%A9%E9%9B%86%28%E5%9B%9B%29.djvu/page1-1280px-%E7%99%BE%E4%B8%80%E5%B1%B1%E6%88%BF%E8%A9%A9%E9%9B%86%28%E5%9B%9B%29.djvu.jpg)


## 📜 歷史與地景背景
結合抽水站動力，水圳呈现出水流逆向攀升的視覺奇觀，是人類改造地景的極致展現。

## 🔍 流域深度解讀
臺灣少見的大型架空導水設施（水橋）。利用鯉魚山與平原位差，實現灌溉水的「跨地型配送」。

## ✨ 亮點特色
- 架空導水設施
- 水往上流視覺
- 地理位差利用
