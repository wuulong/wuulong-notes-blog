# 蘭陽大橋與舊鐵道橋墩

## 簡介
蘭陽大橋橫跨蘭陽溪，是宜蘭南北往來最重要的動脈。在此處可以同時觀察到現代公路橋與過去日治時期鐵道橋的歷史殘跡。

## 觀察重點
- **河床寬度**：蘭陽溪的河床極為開闊，觀察堤防與河道之間廣大的沖積扇。
- **舊橋殘跡**：位於新橋旁的舊鐵道橋墩，見證了交通發展與河川變動。
- **治理刻度**：觀察橋墩上的水位尺與防洪警示，了解宜蘭平原的防洪標準。
