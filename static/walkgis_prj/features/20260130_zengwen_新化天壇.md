# 新化天壇 (受恩宮)

## 簡介
位於新化區，正式名稱為「受恩宮」，是新化地區歷史悠久的信仰中心，主祀玉皇上帝（俗稱天公）。

## 觀察重點
- **信仰核心**：新化老街周邊的三大廟之一，代表了漢人移墾曾文溪中游平原時期的宗教中心。
- **建築美學**：觀察廟宇的燕尾建築與精緻石雕，展現地方鄉紳對信仰的投入。
- **與水脈的關係**：新化位處曾文溪南岸階地，透過信仰可連結先民如何在相對高位之處建立穩固聚落。
