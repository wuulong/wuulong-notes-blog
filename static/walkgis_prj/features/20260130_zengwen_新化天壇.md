# 新化天壇 (受恩宮)

![20260130_zengwen_新化天壇](https://upload.wikimedia.org/wikipedia/commons/thumb/f/f5/%E6%96%B0%E5%8C%96%E5%A4%A9%E5%A3%87%E8%AD%B7%E5%AE%89%E5%AE%AE.jpg/1280px-%E6%96%B0%E5%8C%96%E5%A4%A9%E5%A3%87%E8%AD%B7%E5%AE%89%E5%AE%AE.jpg)


## 簡介
位於新化區，正式名稱為「受恩宮」，是新化地區歷史悠久的信仰中心，主祀玉皇上帝（俗稱天公）。

## 觀察重點
- **信仰核心**：新化老街周邊的三大廟之一，代表了漢人移墾曾文溪中游平原時期的宗教中心。
- **建築美學**：觀察廟宇的燕尾建築與精緻石雕，展現地方鄉紳對信仰的投入。
- **與水脈的關係**：新化位處曾文溪南岸階地，透過信仰可連結先民如何在相對高位之處建立穩固聚落。
