# 達娜伊谷山之美餐廳 (Shamei Indigenous Restaurant)

位於嘉義阿里山鄉山美部落 (Saviki)，緊鄰著名的達娜伊谷自然生態公園。這是一間洋溢著濃厚鄒族文化色彩的原住民風味餐廳。

## 🔍 特色與細節
*   **靈魂料理**: 主打鄒族傳統烹調，包括原木燻烤的山豬肉、香 Q 的竹筒飯、以及採集自周邊山林的時令野味（如大武壠魚）。
*   **水上用餐體驗**: 部分用餐區設於溪流旁的涼亭，旅人能一邊欣賞清澈見底的達娜伊谷溪，一邊品味地道的原民佳餚。
*   **文化展演**: 餐廳周邊常與部落歌舞展演場地銜接，讓旅人的味蕾與聽覺同步沈浸在阿里山的神話故事中。

## 💡 旅人筆記
*   **必點推薦**: 招牌烤苦花魚（鯝魚）與特製小米酒，是山美部落最自豪的招待之物。
*   **地理驛站**: 作為山海圳「原鄉之路」進入山美段落的重要補給站，這裡是旅人交流登山記錄與氣候資訊的匯集點。
*   **預約指南**: 週末及連假人潮眾多，建議大團體需提前一周電話預訂。
