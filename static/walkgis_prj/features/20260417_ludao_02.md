# 將軍岩

屹立於綠島北岸的巨型海蝕柱群，其壯麗的岩層結構紀錄了兩百萬年前的火山噴發與長期的海浪侵蝕。

## 📜 歷史背景 (Historical Context)
由安山岩碎屑岩（集塊岩）構成，因其側面輪廓酷似頭戴盔甲、身穿長袍的將軍在海岸巡視而得名。其垂直的解理與多樣的岩石紋理，是地質學家研究綠島火山演化的範本。

## ✨ 亮點特色 (Highlights & Features)
- **集塊岩紋理**: 觀察岩石中包裹的火山彈與捕獲岩。
- **三色海景**: 岩礁、淺灘與深海呈現出層次分明的藍色。
