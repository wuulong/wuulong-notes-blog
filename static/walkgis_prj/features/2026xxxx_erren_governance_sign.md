# 跨域治理：從對立到聯手的行政里程碑

南萣橋橫跨台南與高雄，此地的治理標誌象徵著兩市與中央政府共同面對二仁溪污染問題的決心。

## 📜 歷史背景
二仁溪身為界河，過去常因行政區劃導致責任推諉。2005年「二仁溪再生願景約定書」的簽署，正式開啟了中央與地方、跨縣市的「聯手治理」時代。此處是觀察跨域行政協調如何改變物理地景的重要節點。

## ✨ 亮點特色
- 台南高雄跨縣市治理節點
- 整治計畫的行政核心隱喻
- 南萣橋文化路徑交會處
- 座標：22.9030, 120.1870
