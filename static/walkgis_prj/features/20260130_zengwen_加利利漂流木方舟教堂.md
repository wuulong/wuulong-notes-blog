# 加利利漂流木方舟教堂 (Galilee Floating Wood Ark Church)

![20260130_zengwen_加利利漂流木方舟教堂](https://lh3.googleusercontent.com/gps-cs-s/AHVAweotLKyiQbuiAqNfSPr1HGC3yQYJ3FgEpkv-Msr7fBkq7kj3j7ek92Mx2c7zAm1x6opONzFf_4aVUQfw4lss-o27wKMBJ8sTIHgSpQCFaatfuF9nTWN0riBZlZmlzTVt_OSO0Rz5lA=s1600-w1200)


## 簡介
這座宛如諾亞方舟的教堂，是利用 2009 年莫拉克風災（88風災）沖刷下的巨大漂流木修築而成。展現了流域居民在災難傷痕後追求心靈平安與環保意識的結合。

## 觀察重點
- **漂流木意涵**：觸摸教堂主結構的巨木，思考曾文溪山區在極端氣候下的水土變遷與能量釋放。
- **方舟地誌**：建築形式模擬方舟，呼應大洪水傳說，也標定了流域信仰中「避風港」的避難座標。
- **環境省思**：透過教堂的解讀影片，思考人類、森林與河流之間脆弱而緊密的依存關係。
