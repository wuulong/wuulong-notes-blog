# 淡水河紅樹林自然保留區 (竹圍)

## 簡介
淡水河紅樹林自然保留區位於新北市淡水區竹圍段，是淡水河與基隆河交匯的出海口感潮地段。此處為淡水與鹹水的交會處，發育出全台灣乃至全球緯度最高、分布最廣的單一「水筆仔」紅樹林純林，並維持著複雜的沼澤生態系。

## 觀察重點
- **水筆仔純林植群**：觀察水筆仔特有的胎生苗、呼吸根與排鹽機制，理解其如何在半海水浸泡的潮間帶土壤中生存。
- **沼澤食物鏈生態**：尋找在紅樹林泥灘地出沒的彈塗魚、小白鷺、招潮蟹等，感受此河口高度的生物生產力。
- **河口環境變遷**：體會捷運淡水線（昔日台鐵淡水線鐵道）與關渡大橋在空間上與此天然保護區的交融關係。
