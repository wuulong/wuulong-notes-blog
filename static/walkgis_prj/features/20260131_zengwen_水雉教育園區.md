# 官田水雉生態教育園區

![20260131_zengwen_水雉教育園區](https://upload.wikimedia.org/wikipedia/commons/thumb/a/ab/%E6%B0%B4%E9%9B%89%E7%94%9F%E6%85%8B%E6%95%99%E8%82%B2%E5%9C%92%E5%8D%80.JPG/1280px-%E6%B0%B4%E9%9B%89%E7%94%9F%E6%85%8B%E6%95%99%E8%82%B2%E5%9C%92%E5%8D%80.JPG)


## 簡介
這裡是為了復育「凌波仙子」水雉而建立的人工濕地，也是台南官田地區重要的生態保育基地。

## 觀察重點
- **人工濕地維護**：觀察人工濕地的曬池與水生植物管理。
- **產業與生態**：水雉與菱角產業的共生關係，理解農業灌溉水系如何支持生物多樣性。
- **志工文化**：與現場志工交流，理解企業（如台積電）與民間團體參與保育的模式。
