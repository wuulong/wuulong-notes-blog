# 官田水雉生態教育園區

## 簡介
這裡是為了復育「凌波仙子」水雉而建立的人工濕地，也是台南官田地區重要的生態保育基地。

## 觀察重點
- **人工濕地維護**：觀察人工濕地的曬池與水生植物管理。
- **產業與生態**：水雉與菱角產業的共生關係，理解農業灌溉水系如何支持生物多樣性。
- **志工文化**：與現場志工交流，理解企業（如台積電）與民間團體參與保育的模式。
