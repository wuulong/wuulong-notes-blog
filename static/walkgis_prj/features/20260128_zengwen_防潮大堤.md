# 曾文溪海口防潮大堤與排水門

![20260128_zengwen_防潮大堤](https://lh3.googleusercontent.com/gps-cs-s/AHVAweqcqPWnPvC1jLMTJ7pTSFuEMr6G4RnfLHpC-8Ki57RTypSy988FT6RgJf7LuGJH_P0hFu9fSRXWPA7Y2n8nrD3nVUDMorXcW4a_s0clx_QB_AZuvlRqPmHx-0vv1mRGsAzMhrA-=s1600-w1200)


## 簡介
此處為曾文溪注入大海之最後一道防線。宏偉的海堤與自動化排水閘門專為應對暴雨與暴潮而設。

## 觀察重點
- **閘門機制**：觀察潮汐變化與內陸排水之調節方式。
- **地型地層**：了解河口沙洲堆積與海岸侵蝕概況。
- **防災視野**：從堤頂眺望曾文溪口全景。
