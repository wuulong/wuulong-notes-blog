# 員山取水口 (天然自湧泉)

## 🌟 亮點描述
蘭陽平原「隱形水庫」的具體露頭。此處可觀察地下伏流受地形阻擠而噴湧出的純淨水源，是理解蘭陽溪伏流循環的最佳場域。

## 📜 歷史背景與深度知識
根據《蘭陽溪流域深度研究計畫》，此點位具有以下核心價值：
- **地質適應**：蘭陽溪沖積扇具備「扇頂入滲、扇端湧出」的機制。此點位位於扇端，展現了高效的大地過濾能力。
- **水利美學**：觀察清澈的湧泉與主流渾濁河水的強烈對比，理解地下水作為宜蘭生命線的重要性。
- **OO-History (伏流物件)**：將地下水視為動態流轉的物件，分析其在蘭陽平原灌溉系統中的定位。
