# 五結防潮閘門 (大閘門)

## 簡介
這裡是冬山河匯入蘭陽溪口的最後門戶。這座巨大的防潮閘門在漲潮時關閉以防止海水倒灌，並在退潮或洪澇時開啟排水，是守護宜蘭平原的重要防洪設施。

## 觀察重點
- **河水交會**：觀察冬山河與蘭陽溪在閘門處的交會情況，兩者含砂量常有明顯對比。
- **機械結構**：觀察大型電動閘門的運作機制與消能工設計。
- **水文化觀景**：這裡是蘭陽溪口視野最開闊的地方之一，可遙望龜山島與三河匯流。

## 💧 水利技術深度解析 (Technical Deep Dive)
### 1. 功能定位：防潮與排水的雙重博弈
五結防潮閘門（冬山河大閘門）的主要任務是解決「潮汐倒灌」問題。
- **漲潮時**：關閉閘門，阻擋太平洋潮水沿著蘭陽溪口逆流進入冬山河，防止低窪平原鹽化與淹水。
- **退潮時**：開啟閘門，將冬山河累積的人工與自然排水迅速導入蘭陽溪口排入大海。

### 2. 結構演進：新舊閘門並行
- **舊大閘門**：建於 1969 年（民國 58 年），是冬山河截彎取直與河川治理的重要起點。採用捲揚式閘門。
- **新大閘門方案**：近年因設施老舊與極端氣候（防洪等級提升），政府在舊閘門旁增建了更具現代化防洪標準的新閘門。新設施在耐震與自動化監控上有顯著提升。

### 3. 觀察提示：消能與泥沙
注意看閘門下游側的消能設施（如：消能塊、副壩）。由於蘭陽溪是著名的「多砂河」，而冬山河在整治後流速較慢、含金量低，匯流處常可見「清濁分明」的現象，這是動態的水理觀察重點。
