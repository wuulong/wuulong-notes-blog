# 山海驛站-新美尼亞后薩獵人營 (Niahosa Hunter Camp)

![20260202_shj_poi_035](https://upload.wikimedia.org/wikipedia/commons/thumb/1/1a/%E6%AC%BD%E5%AE%9A%E4%B8%AD%E6%A8%9E%E6%94%BF%E8%80%83%28%E5%85%AD%E5%8D%81%E4%B8%80%29.djvu/page1-1280px-%E6%AC%BD%E5%AE%9A%E4%B8%AD%E6%A8%9E%E6%94%BF%E8%80%83%28%E5%85%AD%E5%8D%81%E4%B8%80%29.djvu.jpg)


新美尼亞后薩獵人營位於嘉義縣阿里山鄉新美部落（Niahosa）。「尼亞后薩」意指古老的部落，這裡是山海圳「原鄉之路」極具鄒族獵人文化色彩的體驗基地。營地致力於傳承與展示鄒族與自然和諧共生的智慧。

## 🔍 特色與細節
*   **獵人文化傳承**: 營地提供專業的獵人文化體驗，包含傳統陷阱製作解說、弓箭射擊、鄒式風味餐，以及對自然倫理的深度詮釋。
*   **山海驛站與護照服務**: 作為官方指定的山海驛站，此處售有山海圳集章護照，並提供集章服務。
*   **旅人專屬優惠**: 持有山海圳護照的旅人造訪獵人營，可享有特定餐飲服務或營位分租的折扣優惠（詳見護照說明或現場公告）。

## 💡 旅人筆記
*   **深度補給站**: 提供旅遊摺頁、休憩空間、飲水補充與洗手間。在挑戰漫長山路之際，這裡是感受部落熱情與重整裝備的理想停靠點。
*   **預約制體驗**: 若計畫參與獵人營的導覽或享用風味餐，建議提前預約，以確保完整的文化沈浸體驗。
*   **部落共好**: 獵人營的經營與部落生態旅遊緊密結合，旅人的造訪與消費能實質支持部落的文化延續與青年返鄉。
