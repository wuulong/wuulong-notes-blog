# 正統鹿耳門聖母廟

## 簡介
宏偉的建築群仿若紫禁城，象徵著這片由曾文溪泥沙堆疊出的「浮覆地」上強大的宗教能量與族群生命力。

## 觀察重點
- **空間尺度**：感受在廣闊平原上建立起的巨大神域，這與下游空曠的地景形成強烈對比。
- **古廟遺構**：理解古廟如何在曾文溪氾濫中傾圮，又如何在浮覆地上重生的歷史。
