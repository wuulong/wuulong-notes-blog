# 思源埡口

## 🌟 亮點描述
蘭陽溪與大甲溪的分界點。此地展現了蘭陽溪垂直地景的最上層特徵：冷溫帶植被與板岩地層邊界。

## 📜 歷史背景與深度知識
根據《蘭陽溪流域深度研究計畫》，此點位具有以下核心價值：
- **地質適應**：觀察蘭陽平原著名的「沖積扇群」與「浮腹地」沙地如何形塑當地的產業與部落分佈。
- **治理技術**：從日治時期的「警察駐在所（埤亞南/流興）」到戰後的水流自動控制閘門，展現了不同政權對流域空間的規訓。
- **垂直地景**：此處代表蘭陽溪垂直剖面中特定的海拔生態位（生態、族群與統治方式的疊合）。
