# 茄拔溪渡槽橋

## 簡介
位於善化側，是嘉南大圳輸水系統中重要的跨河節點。其結構反映了當時精密的土木工程技術。

## 觀察重點
- **橋體細部**：觀察鉚釘與鋼樑之結合處。
- **河道景觀**：從橋上俯瞰茄拔溪與周邊地形。
