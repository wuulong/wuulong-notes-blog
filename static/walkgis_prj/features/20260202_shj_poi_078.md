# 住-大埔山莊 (Dapu Villa)

大埔山莊座落於曾文水庫湖畔的大埔聚落內，提供旅人一個平價且位置優越的夜宿選擇。

## 🔍 特色與細節
*   **優越地理位置**: 緊鄰大埔旅遊資訊站與湖濱公園，是山海圳綠道挑戰者由「大圳之路」轉入「原鄉之路」的最佳中繼點。
*   **護照優惠驛站**: 持有官方護照的旅人，在此訂房入住可享有專屬折扣方案（請於訂房時出示）。
*   **基本設施完備**: 提供簡單、乾淨、安全的套房與通舖服務。

## 💡 旅人筆記
*   **生活機能**: 出門即有大埔老街多樣化的砂鍋魚頭特色餐飲。
*   **資源整備**: 此處是大埔區段重要的住宿集中點，對於團體徒步者具備較佳的接待能力。
