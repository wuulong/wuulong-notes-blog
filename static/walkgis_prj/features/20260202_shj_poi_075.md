# 住-救國團曾文青年活動中心 (Zengwen Youth Activity Center)

位於曾文水庫風景區內，這座具備獨特建築美學的中心是山海圳「大圳之路」中段最重要的住宿、集會與戶外教育基地。

## 🔍 特色與細節
*   **環保大船建築**: 建築物順應地形而建，其船型外觀象徵著在智慧之水的引導下揚帆啟航。中心內部設有各級套房與團體房。
*   **護照優惠驛站**: 作為官方認證的合作驛站，持有山海圳護照的旅人在此訂房或用餐（特定方案）可享有專屬折扣。
*   **生態觀察場**: 園區內林木茂盛，清晨或傍晚常可見到多樣的鳥類與昆蟲，是都市難見的自然樂園。

## 💡 旅人筆記
*   **體力中繼**: 這裡是從平原進入深山前最好的體力補給與裝備調整點。
*   **入園須知**: 由於中心位居水庫風景區內，進入時需依照該風景區之收費標準，住宿旅人可享有特定抵扣（請提前確認）。
*   **星空陪伴**: 遠離光源的大草皮，是徒步旅行者沈澱思緒的最佳場所。
