# 山海驛站-阿里山轉運站 (Alishan Transport Station)

![20260202_shj_poi_034](https://lh3.googleusercontent.com/gps-cs-s/AHVAwepQxSXRDeVyp13l7GOnL1TTFUx3WgMk-N7ABqbm1wxklbt1-mdhgg0VUTYNGacS8UBRGLIcagsIqHEHAnlAQcfH9IUXBquf2iVcXWfiIRip7jnO1-0ntZqbN9FhQssuEcP9dU1beg=s1600-w1200)


阿里山轉運站是進入阿里山國家森林遊樂區的交通門戶。在山海圳國家綠道的旅程中，它是「聖山之路」最重要的交通樞紐與大型物資整備站，串聯了大眾運輸與高深山探險的動線。

## 🔍 特色與細節
*   **交通轉運樞紐**: 於 2017 年啟用，整合了台灣好行、嘉義客運與園區內接駁巴士。有效解決了森林遊樂區入口的人車擁擠問題，並提供電子售票與多元支付服務。
*   **現代化建築設計**: 建築造型簡約流暢，內部設有景觀大窗，讓旅人在候車時亦能欣賞阿里山的雲霧變化。
*   **護照購買與入園優惠**: 作為官方指定的山海驛站，此處售有山海圳集章護照。持有護照的旅人可享有森林遊樂區門票折扣（依現場公告為準）。

## 💡 旅人筆記
*   **關鍵補給站**: 轉運站內設有 7-ELEVEn 等連鎖超商，是進入聖山（登頂）段落前，最後一個可進行大規模行動糧與飲用水補給的據點。
*   **行李託運服務**: 提供寄物櫃與相關交通指引，方便輕裝進入森林園區內健行。
*   **即時資訊中心**: 提供阿里山森林鐵路班次與即時山區氣候建議，是旅人掌握山林脈動的關鍵入口。
