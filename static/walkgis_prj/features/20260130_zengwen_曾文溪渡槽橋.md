# 曾文溪渡槽橋

## 簡介
嘉南大圳重要的「水橋」設施，負責帶領「南幹支線」跨越曾文溪，供應南部農田灌溉用水。

## 觀察重點
- **新舊並存**：此處有日治時期興建的老渡槽橋（已被指定為文化資產）與後期新建的輸水橋，展現不同時代的土木技術。
- **水流交叉**：現場感受「大圳的水流越過大河的上方」這種人工景觀與自然地理的交融。
- **八田與一的藍圖**：這裡是嘉南大圳整體系統中，動員人力物力極大的工程壯舉。
