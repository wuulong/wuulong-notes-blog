# 山田小館 (Yamada Restaurant)

位於嘉義縣阿里山鄉達邦部落，山田小館以其細膩、美味且極具飽足感的山產料理著稱。它是山海圳徒步挑戰者抵達達邦大社後，補充登山能量的熱門餐飲站。

## 🔍 特色與細節
*   **在地山產菁華**: 提供多樣化的在地野蔬料理與肉類主食，調味恰到好處，完美呈現了高山食材的原味與鮮甜。
*   **家庭式氛圍**: 用餐環境潔淨且充滿溫馨的家庭感，讓人有種回到深山老友家中作客的舒適感。
*   **人氣點餐**: 其推薦的組合合菜或個人套餐，份量誠意十足，是應對接下來聖山路段高強度體能消耗的最佳前哨戰。

## 💡 旅人筆記
*   **口碑推薦**: 這裡在登山圈中小有名氣，經常能在此遇到同樣挑戰山海圳的同好。
*   **位置建議**: 位處達邦聚落核心區，周邊機能便利。
*   **隱藏好味**: 推薦詢問當日採摘的「今日限定野蔬」，常有意想不到的爽脆美味。
