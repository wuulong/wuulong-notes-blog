# 護照優惠-大埔山莊 (Dapu Villa)

![20260202_shj_poi_057](https://lh3.googleusercontent.com/places/ANXAkqFT0nc21xPYRDLOhcK5MJGmRBLveaSBV3zNgSBesKoQn59x1vQwDWQV-xJAb7O-CnB1INCXeCwYqEM2JlpCFXFqoXPlgrX5rxs=s1600-w1200)


大埔山莊位於嘉義縣大埔鄉，緊鄰大埔旅遊資訊站，是山海圳國家綠道旅人翻越烏山嶺、環繞曾文水庫後的理想平價住宿地點。

## 🔍 特色與細節
*   **平價親民**: 提供乾淨、簡單的套房設施，深受單車族與平價徒步者的青睞。
*   **護照優惠**: 作為山海圳國家綠道合作夥伴，持有實體集章護照的旅人，在此訂房入住可享有專屬專案優惠（請於訂房時告知）。
*   **地理優勢**: 對面即是具備湖景視野的公園與大埔老街，生活與觀光機能便利。

## 💡 旅人筆記
*   **補給之站**: 周邊有多家大埔特色砂鍋魚頭餐廳，是補充體能的好選擇。
*   **訂房提醒**: 由於大埔鄉住宿資源相對較少，建議旅遊旺季或例假日提前電話預約。
