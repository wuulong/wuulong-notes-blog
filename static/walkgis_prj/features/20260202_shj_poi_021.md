# 山海驛站-里佳資訊站 (Lijia Information Station)

![20260202_shj_poi_021](https://upload.wikimedia.org/wikipedia/commons/thumb/6/6c/Lalauya.JPG/1280px-Lalauya.JPG)


里佳資訊站位於嘉義縣阿里山鄉的「藍色部落」里佳，歸屬阿里山國家風景區管理處管轄。它是山海圳國家綠道中海拔較高的重要服務節點，為穿梭於山林間的徒步者提供關鍵的後勤支援。

## 📜 歷史背景 (Historical Context)
*   **藍色部落**: 里佳因環境極其純淨、天空清澈湛藍、星空深邃而得名。其地理位置孤立，保留了濃厚的鄒族傳統文化。
*   **文化建築**: 資訊站的建築設計仿照鄒族傳統的「庫巴」(KUBA，男子集會所) 樣式，旨在向部落傳統致敬，並成為當地的文化地標。

## ✨ 亮點特色 (Highlights & Features)
*   **山海驛站服務**:
    - **基礎備援**: 提供洗手間、飲水機、手機充電、無線網路 (Wi-Fi) 等基礎服務。
    - **深度解說**: 館內提供里佳部落的自然生態（如螢火蟲、觀星點）與步道資訊（如風流洞步道、大巨石坂）。
*   **文產展示**: 定期展示當地青年的藝術作品，並提供里佳特產（如愛玉、部落咖啡、轎篙筍）的資訊導引。
*   **跨年晚會**: 站前廣闊的廣場是部落辦理活動的核心空間，甚至是重要的緊急避難點。

## 🍴 在地美食 / 服務資訊
*   **建議體驗**: 部落愛玉、高山咖啡。
*   **開放時間**: 每日 08:00 - 17:00。
*   **周邊步道**: 建議可由資訊站出發前往「風流洞步道」體驗鄒族的傳統生活痕跡。
