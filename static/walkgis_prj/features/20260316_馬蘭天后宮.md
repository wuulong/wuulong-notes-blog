# 📍 馬蘭天后宮 (朝天宮)

## 📜 歷史背景
光緒十五年（1889年）由統領張兆連所建，位於卑南馬蘭街，是當時地方官軍與居民的信仰中心。

## ✨ 亮點特色
- **建築歷史**: 見證了清末對台東地區的經營與防務。
- **地理位置**: 位於馬蘭聚落核心。
