# 隆田生態園區

![20260131_zengwen_隆田生態園區](https://lh3.googleusercontent.com/gps-cs-s/AHVAwerzfi0o9VG1UuWNKXZA2uALLoNm7Ko9lrDTVV0cMnA8h5eeBnWzE5zEmJZCP9RFgtAhLJ0kdJWa_d0B6tbJLn4RYAzAAe5PBRKk2gc57Df9RWvjhbUR4ppwdJVGcG5Qu6d-7C0TKw=s1600-w1200)


## 簡介
由舊隆田軍營改建而成的生態公園，保留了部分軍事遺構並融入現代景觀設計。

## 觀察重點
- **場域轉生**：觀察閒置軍事設施如何轉型為優質的市民休憩空間。
- **植被與生態**：原始老樹的保留與新景觀的融合，展現良好的綠基礎設施設計。
