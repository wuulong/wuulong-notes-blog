# 📍 秀姑漱玉 (Xiugu Shuyu)

秀姑巒溪下游最著名的自然景觀，因其潔白如玉的巨石遍布河床而得名。

## 📜 歷史背景
「秀姑漱玉」位於長虹橋下游附近的溪床中。這裡的白色岩塊主要屬於 **都巒山層港口石灰岩**，地質年代約為中新世晚期（約510-520萬年前）。這些石塊原本是古海洋中的珊瑚礁與石灰藻堆積而成，後經地殼抬升與秀姑巒溪長年累月的切割、沖蝕與磨蝕，洗練出其潔白光滑的外表，宛如漱洗過的美玉。

## ✨ 亮點特色
- **花蓮八景之一**: 這是一處結合了激流、峽谷與奇石的天然畫卷。
- **豐富化石**: 岩塊中常可觀察到抱球藻、珊瑚、有孔蟲等古海洋生物化石，是極佳的地質教室。
- **地形美學**: 溪水在白色石灰岩間激盪出的水花，襯托出東台灣大山大水的壯闊之美。
