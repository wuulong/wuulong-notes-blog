# 南化水庫大壩與馬蹄形溢洪道

## 簡介
南化水庫位於曾文溪支流後堀溪上，是台南與高雄地區重要的民生用水來源。其最著名的特色是全台唯一的「馬蹄形自然溢洪道」。

## 觀察重點
- **馬蹄形溢洪道**：無閘門控制，水位滿時自然溢流。
- **曾文南化聯通管**：了解兩大水庫如何進行「餘裕水資源」調度。
- **大壩風光**：遠眺後堀溪上游集水區。
