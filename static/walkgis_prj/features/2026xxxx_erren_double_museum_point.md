# 雙博物館自行車道：串聯文明與水文的絲帶

這是一條串聯「台灣歷史博物館」與「奇美博物館」的國家級級自行車道，其精華路段正位於二仁溪堤頂。

## 📜 歷史背景
雙博物館自行車道計畫是台南市重點推動的觀光綠廊，透過二仁溪堤頂道路的整備，將原本隔離的河岸空間轉化為市民可親近的休憩徑路。它象徵著二仁溪從「封閉的排水溝」進化為「開放的文化走廊」。

## ✨ 亮點特色
- 串聯奇美博物館與台史博
- 堤頂平緩徑路，視野絕佳
- 國家級綠道概念實踐
- 座標：22.9230, 120.2350
