# 滿月圓國家森林遊樂區

## 簡介
滿月圓國家森林遊樂區位於新北市三峽區山區，因座落於滿月圓山（外形圓潤似滿月）之下而得名。園區屬於大漢溪水系支流三峽河上游的大豹溪與蚋仔溪流域。此處擁有豐富的瀑布、溪流、森林與鳥類生態，是大漢溪與三峽河水系中非常關鍵的上游生態與水源涵養區。

## 觀察重點
- **滿月圓瀑布與處女瀑布**：觀察蚋仔溪上游受地表隆起與河川侵蝕切割所形成的壯麗瀑布，處女瀑布高度落差極大，水氣極盛。
- **蚋仔溪生態步道**：觀察蚋仔溪的河床地形（包含巨石、急流與壺穴雛形），以及溪流環境中的溪流鳥類（如鉛色水鶇、紫嘯鶇）。
- **柳杉與森林涵養**：園區內的大片人工柳杉林與天然闊葉林，體現了雪山山脈尾稜中低海拔森林的水源涵養與生物多樣性功能。
