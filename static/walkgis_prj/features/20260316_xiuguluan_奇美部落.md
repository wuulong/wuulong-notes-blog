# 📍 奇美部落 (Kiwit)

被譽為「活的博物館」，是秀姑巒阿美族群中最古老的發源地，完整保留了嚴謹的年齡階級制度。

## 📜 歷史背景
奇美部落阿美族語名為 **"Kiwit"**，意指一種堅韌的藤蔓植物「海金沙」，象徵部落強韌的生命力。由於地理位置深處海岸山脈峽谷中，早期對外交通極端不便（直到1986年才有公路），使得這裡在現代化巨輪下得以保留最純粹的傳統習俗。19世紀末，奇美部落曾參與反抗清廷「開山撫番」政策，見證了東台灣開發史中的激盪歲月。

## ✨ 亮點特色
- **活的博物館**: 部落內展示傳統家屋與生活器物，並嚴格維持著阿美族傳統的「各階級各司其職」的社會結構。
- **Tatadok 文化泛舟**: 不同於觀光泛舟，「Tatadok」（意為順流行走）更強調與溪水的互動，包含撒網、捕魚、石頭火鍋等野外生存智慧。
- **水上思路**: 這裡曾是過去物資逆流而上送入縱谷的重要補給節點。
