# 朝日溫泉

全球罕見的海底湧出溫泉，是綠島後火山活動地熱與海水循環系統共同交織的地質能源奇蹟。

## 📜 歷史背景 (Historical Context)
泉源位於綠島東南端的潮間帶珊瑚礁中。海水滲透地底加熱後，沿構造斷層升湧。它是綠島三大「自然原力」之一，曾是島民生活中的熱能來源與精神慰藉。

## ✨ 亮點特色 (Highlights & Features)
- **海底熱對流**: 觀察潮汐起伏如何影響泉水的湧出與溫度調節。
- **日出交響**: 在海平面第一道曙光中泡湯，感受地熱與天光的對位。
