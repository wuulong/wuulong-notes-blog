# 三重夜宿點

位於台北盆地西側的三重區，是這趟河流大縱走在跨越山脈與地理邊界後的「跨界機能與夜宿點物件」。

## 🛌 現地考掘與感官經驗
*   **跨盆地的夜間長征**：
    為了避開隔日清晨雪山隧道極其嚴重的通勤塞車潮，選擇在深夜十一點泡完湯後發動車輛直上國道五號，穿過雪隧、跨越整座台北市，抵達三重夜宿。
*   **流域與交通邊界的轉換**：
    這段深夜駕駛是一場極具速度感的「地理空間大跨越」。我們從太平洋側的蘭陽溪流域，在短短一個多小時內，跨越了雪山山脈大分水嶺，進入淡水河下游的三重盆地邊緣。這代表了水文探索與城市生活機能的完美切換，為這趟縱走畫下安全且極具效率的句點。
