# 護照優惠-特富野民宿 (Tefuye Guesthouse)

![20260202_shj_poi_060](https://lh3.googleusercontent.com/places/ANXAkqG_m8nSa2VP61LYEukN9whrN8kZsul9LKkrpcwVtFw33_7CvdgJHIJjY1C-4Y7A1VoN5d9Xg9GxcJrKRd5jQ54_rNVZ_7UJOfA=s1600-w1076)


特富野民宿座落於歷史悠久的阿里山鄒族特富野大社內，是旅人深入體驗部落文化與參與歲時祭儀的絕佳住宿選擇。

## 🔍 特色與細節
*   **深山大社氛圍**: 民宿與鄒族神聖的集會所「庫巴」(Kuba) 僅有數百公尺之遙，旅人能在此感受到古老部落的寧靜與莊嚴。
*   **護照優惠**: 作為山海圳國家綠道合作夥伴，持有實體集章護照的旅人，在此訂房入住可享有專屬專案優惠（入住前請先電話洽詢）。
*   **原民風情**: 民宿經營者多為在地族人，能為旅人提供真實的部落生活資訊與導覽建議。

## 💡 旅人筆記
*   **文化尊重**: 入住期間請尊重部落的傳統生活規範，尤其在祭典期間，請務必遵循民宿主人的引導與禁忌提醒。
*   **山間補給**: 特富野部落內有簡易柑仔店，但建議主要的入山糧草與整備在大埔或阿里山先完成。
*   **景觀優點**: 陽台望出去多為疊翠的山巒與雲海，非常適合渴望遠離世俗的旅人。
