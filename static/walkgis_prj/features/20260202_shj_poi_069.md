# 住-小農家族民宿 (Small Farmer Family B&B)

位於台南市善化區，緊鄰嘉南大圳南幹線與山海圳「大圳之路」段。這是一家洋溢著農村溫馨氛圍的平價民宿。

## 🔍 特色與細節
*   **在地的溫度**: 由當地回鄉青年或老農家庭經營，提供簡約乾淨的客房服務。
*   **地理節點**: 距離茄拔天后宮與善化草莓園區極近，是想要體驗深度農民生活旅人的好去處。
*   **田園視角**: 推開窗常可見到綠油油的稻田或季節性的草莓園，完美契合山海圳中段的農業地景。

## 💡 旅人筆記
*   **親切互動**: 民宿主人常會分享關於大圳供水與在地作物（如胡麻、草莓）的小知識。
*   **安靜清幽**: 避開了鬧區的喧囂，提供旅人一個能聽見蟲鳴鳥叫的休息環境。
*   **入站補給**: 適合由市中心徒步進入大圳段落後，作為首夜或第二夜的下榻點。
