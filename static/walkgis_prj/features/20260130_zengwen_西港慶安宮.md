# 西港慶安宮 (Xigang Qing-An Temple)

![20260130_zengwen_西港慶安宮](https://upload.wikimedia.org/wikipedia/commons/thumb/b/b3/2025.01.29_Xigang_Qingan_Temple.jpg/1280px-2025.01.29_Xigang_Qingan_Temple.jpg)


## 簡介
西港慶安宮是「西港刈香」（台灣第一大香）的起源地。在曾文溪流域的水文史中，它扮演了「倖存者共同體」的核心。

## 觀察重點
- **香路與災難圖譜**：分析刈香活動涵蓋的「九十六村落」香路，這實際上是一張歷史上曾文溪氾濫區的倖存聚落分布圖。
- **拜溪墘祭儀**：了解地方信仰如何對應「青瞑蛇」的改道威脅，尋求心靈與空間的雙重防禦。
- **改道歷史座標**：慶安宮所在地曾經接近舊河道，可觀察廟宇周邊地貌與河流改道後的商業重心轉移。
