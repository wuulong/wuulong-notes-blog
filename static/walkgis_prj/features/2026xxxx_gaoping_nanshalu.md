# 南沙魯部落：堅強留鄉者

![2026xxxx_gaoping_nanshalu](https://upload.wikimedia.org/wikipedia/commons/thumb/e/ee/Namasia_KH.svg/1280px-Namasia_KH.svg.png)


## 📜 歷史與地景背景
拒絕遷村壓力後，利用善款與自主力量建設「避難救命方舟」，是人類與河流災害博弈的勇氣象徵。

## 🔍 流域深度解讀
那瑪夏區最南端門戶，莫拉克災區現場。部落展現強烈留鄉意識，拒絕下山，自主興建避難屋防衛家園。

## ✨ 亮點特色
- 堅強留鄉者
- 自主避難屋系統
- 裂縫中的重生
