# 武陵農場牛頓蘋果樹 (Newton's Apple Tree in Wuling)

## 📌 空間屬性
- **座標**：24.3450052, 121.3082054
- **類型**：科學文化地標

## 📜 OO-History 考掘
- **【科學符號的全球流轉】**：這棵蘋果樹是從英國伍爾斯索普莊園（Woolsthorpe Manor）那棵啟發牛頓萬有引力定律的母樹，經過多代分株繁殖，最終跨越半個地球種植於台灣武陵農場的高海拔溫帶氣候區。
- **【時空交感】**：看著樹上結著同樣的蘋果，科學史上的「萬有引力」符號與台灣的高山溫帶農業在此處產生了極為特別的奇妙互文。
