# 綠洲山莊 (八卦樓)

1972 年起興建的高度戒備監獄（國防部感訓監獄），其 X 型放射狀建築設計代表了極致的人身與意識形態監控。

## 📜 歷史背景 (Historical Context)
為應對泰源事件後加強管控的需求而建，關押過無數爭取台灣民主的政治受難者。監獄內部通風不良、空間壓抑，發展出特殊的「隔牆傳訊」與隱秘的生命書寫文化，現為國家人權博館的核心展示區。

## ✨ 亮點特色 (Highlights & Features)
- **八卦樓結構**: 觀察中央管制室如何監控四條放射狀走廊，感受權力之眼的運作。
- **獨居房體驗**: 在狹窄的空間中體會長時間禁錮的心境轉折。
