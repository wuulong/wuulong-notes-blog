# 📍 寶桑 (Baosang)

「寶桑」是台東市的老地名與發源地，見證了台東從原民部落到漢人聚落的轉型。

## 📜 歷史背景
「寶桑」源於卑南族語 **"Paposogan"** (或 Posong)，意指「一片一望無際、適合居住耕作的地方」。清朝咸豐年間（約1860年），屏東枋寮商人鄭尚在此建立據點與原住民進行貿易，隨後吸引更多漢人移墾，形成台東平原上第一個漢人聚落。

在清領時期的開發史上，寶桑曾是卑南溪口的重要貿易點，與打狗港（今高雄港）之間有戎克船往返。這裡也發生過著名的「大庄事件」等歷史衝突與調和過程。

## ✨ 亮點特色
- **台東市前身**: 寶桑庄是現代台東市發展的起點。
- **昭忠祠記憶**: 原設有昭忠祠紀念開拓時期殉難官兵，後因颱風毀損，牌位目前供奉於台東天后宮。
- **老街文化**: 寶桑路一帶仍保留許多古早味小吃（如寶桑湯圓）與老聚落的生活氣息。
