# 龜丹溫泉

![20260128_zengwen_龜丹溫泉](https://lh3.googleusercontent.com/gps-cs-s/AHVAweoj8B-alVSVu1tKg4lhRrZe3kmet1aqEs467P4-k9yRW0Jf1NgpiWfIEFzXCRHYL0YhROxw0AHfI4mT9u9w_bEeFpTHM4JrLnLVd_wzFf-gDZnF0ZahbrLYVkkqZ6AZncAi-UKC=s1600-w1200)


## 簡介
龜丹溫泉是曾文溪流域內著名的碳酸氫鈉泉（美人湯），開發歷史悠久，環境安靜幽美。

## 觀察重點
- **溫泉地質**：了解地熱與斷層帶的關係。
- **休閒節奏**：觀察山區聚落的溫泉開發與河流共生模式。
