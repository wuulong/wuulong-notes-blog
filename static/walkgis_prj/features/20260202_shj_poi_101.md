# 達邦街角複合式餐飲 (Dabang Corner Dining)

![20260202_shj_poi_101](https://upload.wikimedia.org/wikipedia/commons/thumb/c/c7/Dabang_tribe_in_the_mountain.jpg/1280px-Dabang_tribe_in_the_mountain.jpg)


位於嘉義縣阿里山鄉達邦部落的核心街角，這是一間深獲部落族人與山海圳旅人一致好評的在地餐廳。

## 🔍 特色與細節
*   **高 CP 值部落餐**: 以份量紮實、價格親切的個人份套餐聞名。內容常包含香噴噴的山豬肉、當季高山鮮蔬及清甜的湯品。
*   **窗外即是風景**: 餐位設計能讓旅人在享受美味的同時，飽覽阿里山綿延的綠意與雲霧繚繞，提供感官的雙重放鬆。
*   **多元選擇**: 提供各類複合式簡餐與飲品，是進入聖山區段前重要的體力增強站。

## 💡 旅人筆記
*   **補給黃金位**: 位處達邦部落主要幹道交會處，周邊步行即可抵達部落警察局與便利雜貨店。
*   **在地人也愛**: 這裡常有部落族人用餐，是觀察阿里山大社生活最自然的據點。
*   **必嚐推薦**: 這裡的山豬肉套餐火候十足，與軟 Q 的在地米飯是絕配。

## 📬 資訊卡

- **主要特色**: 部落平價簡餐、景觀用餐空間、交通位置便利
