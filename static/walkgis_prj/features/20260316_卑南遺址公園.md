# 📍 卑南遺址公園

## 📜 歷史背景
卑南遺址是台灣規模最大、出土文物最豐富的石板棺墓葬群遺址，代表了新石器時代晚期的卑南文化。其規模與精美的玉器顯示了當時高度發展的社會組織。

## ✨ 亮點特色
- **考古地位**: 國定遺址。
- **風景**: 園區內有廣闊草坪與遺址現場。
