# 南山村 Pyanan

## 🌟 亮點描述
蘭陽溪上游最大的沖積扇聚落。泰雅族埤亞南社在此利用「扇端湧泉」發展高冷蔬菜。日治時期曾發生強制分社遷徙。

## 📜 歷史背景與深度知識
根據《蘭陽溪流域深度研究計畫》，此點位具有以下核心價值：
- **地質決定論 (Alluvial Fan)**：南山村位於蘭陽溪上游最大的沖積扇群，利用「扇端湧泉」發展出規模龐大的高冷蔬菜產業。
- **權力地景 (Kanan vs Koxao)**：對合「加腦蘭 (Kanan)」原始社址與日治「警察駐在所」位置。1920年代，日方強迫頭目遷入駐在所旁的「鼻狀地 (Koxao)」，形成全景敞視的空間監控。
- **垂直地景**：此處代表海拔約 1,100m 的垂直剖面，是泰雅族生存策略與殖民統治技術的碰撞點。
