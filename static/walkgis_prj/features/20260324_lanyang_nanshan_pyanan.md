# 南山村 Pyanan

## 🌟 亮點描述
蘭陽溪上游最大的沖積扇聚落。泰雅族埤亞南社在此利用「扇端湧泉」發展高冷蔬菜。日治時期曾發生強制分社遷徙。

- **垂直地景**：此處代表蘭陽溪垂直剖面中特定的海拔生態位（生態、族群與統治方式的疊合）。
