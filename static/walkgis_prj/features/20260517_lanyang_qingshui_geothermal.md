# 清水地熱公園 (Qingshui Geothermal Park)

## 📌 空間屬性
- **座標**：24.6118089, 121.6365653
- **類型**：地熱湧泉 / 體驗地景

## 📜 OO-History 考掘
- **【地質能量物件】**：源於清水溪谷的強烈高溫自湧溫泉，早期為中油與台電地熱發電的試驗場。
- **【生活適應】**：極為專業且豐富的庶民採買生態。園區外的自帶攤販提供海鮮等精緻食材，並贈送「有洞的鋁箔紙」（免除現場租借用具之費用），體現了遊客與在地攤商對公共地熱資源的高度智慧化適應。
- **【風味物件】**：溫泉玉米極度甜美，而「鳥蛋」則是園區內買不到的隱藏食材。
