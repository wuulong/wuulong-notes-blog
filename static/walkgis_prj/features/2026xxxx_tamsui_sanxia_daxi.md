# 大溪三坑水利網

## 簡介
大溪三坑水利網位於桃園市龍潭區三坑里，是大漢溪中游農業開發的核心命脈。這裡有清代「三坑老街」的商貿遺跡、早期的「三坑仔隘」歷史防禦線，更重要的是興建於日治時期的「桃園大圳」進水口與取水隧道，它是桃園台地能轉化為北部糧倉的關鍵工程。

## 觀察重點
- **桃園大圳進水口與進水閘門**：觀察大漢溪旁巨型混泥土取水建築，了解日治大圳如何在此截水，引入暗渠，跨越桃園台地灌溉。
- **三坑仔隘與老街水圳**：走訪三坑老街（如洗衫坑），觀察早期庄頭利用水圳進行洗滌與灌溉的庶民生活空間。
- **大漢溪河階地貌**：在三坑河濱觀察大漢溪歷經多次地殼隆起與侵蝕切割所形成的壯麗多級河階地型。
