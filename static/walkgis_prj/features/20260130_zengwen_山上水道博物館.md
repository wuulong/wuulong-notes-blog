# 臺南山上花園水道博物館

## 簡介
前身為日治時期「臺南水道」，於 1922 年完工，是亞洲早期規模巨大的自來水供應系統，從曾文溪取水。

## 觀察重點
- **取水原理**：了解當時如何利用曾文溪水源，經過沈澱、過濾、加壓（快濾筒室）後，將水輸送至大目降（新化）淨水池，再供應台南市區。
- **現代化地標**：觀察宏偉的紅磚建築，這是曾文溪對台南城市現代化（公共衛生）發展的核心貢獻。
- **濱野彌四郎**：紀念這位對台灣水道建設有巨大貢獻的工程師。
