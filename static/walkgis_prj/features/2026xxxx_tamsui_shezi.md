# 社子島島頭公園

## 簡介
此處為淡水河與基隆河的交匯點，擁有 270 度的無敵河景。由於長期受限建政策影響，保留了台北都會區難得的鄉村景觀與開闊濕地。

## 觀察重點
- **河流交匯**：觀察兩條河流匯合處的潮汐變化與水流色彩差異。
- **低矮防洪牆**：與台北市區高大堤防對比，感受社子島特殊的防洪計畫與社會脈絡。
- **濕地生態**：觀察紅樹林與水鳥分佈。
