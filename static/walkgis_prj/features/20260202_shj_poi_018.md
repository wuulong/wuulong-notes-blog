# 台 3 線 333 公里處 (Highway 3 Milestone 333 - Dabu Bridge)

位於嘉義縣大埔鄉，此處的重要地標為著名的「大埔橋」。大埔橋橫跨曾文溪峽谷，是台 3 線「澐密戰道」段落中極具視覺震撼力的景點。對許多旅人而言，「333」不僅是連號的里程數字，更是進入曾文水庫大埔風景區的重要門戶。

## 🔍 特色與細節
*   **峽谷壯觀景致**: 大埔橋採用長跨徑、無橋墩落於河床的設計，保護了曾文溪的河道與自然景觀。站在橋上，可俯瞰深邃的曾文溪峽谷與險峻的岩層，感受大自然的鬼斧神工。
*   **曾文水庫上游**: 此處可觀察到曾文水庫上游的蓄水狀況。枯水期與豐水期呈現截然不同的地貌圖案，是攝影愛好者的取景秘境。
*   **澐密戰道中繼**: 台 3 線此段以蜿蜒山路聞名，被稱為單車與重機騎士的挑戰聖地。333 公里的里程碑象徵著一段旅程的堅持與跨越。

## 💡 旅人筆記
*   **拍照留念**: 里程牌「333」因數字諧音吉祥且罕見，是許多環島或挑戰山海圳旅人的必備打卡點。
*   **小心限速與過彎**: 該區段道路曲折，停留拍照時請務必確保車輛停放在安全處，並嚴格遵守速限與警示。
*   **風雨影響**: 山區道路易因豪雨造成落石或坍方，造訪前建議確認天候與即時路況。
