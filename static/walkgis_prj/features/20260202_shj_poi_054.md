# 護照優惠-烏山頭湖境渡假會館 (Hujing Resort)

![20260202_shj_poi_054](https://lh3.googleusercontent.com/gps-cs-s/AHVAweqqoV774QUpxjqb1WsFJ-o6vXJvOLk_jsgRVaS1HoMYGwuyw1UbjH6C5ViVYFdhAjiuGdep9gGhY83jeBnI_edvIaVnXI89J5XCVSTTYWeDJevOWuaDTlEYYahspDgEAqrzwiKMig=s1600-w1200)


湖境渡假會館位於烏山頭水庫風景區內，擁有俯視整個水庫大壩與湖光山色的絕佳地理位置，是山海圳徒步者在「大圳之路」段落理想的住宿選擇。

## 🔍 特色與細節
*   **半山秘境**: 會館座落於山坡上，視野開闊，讓旅人能在靜謐的環境中洗去徒步的疲累。
*   **護照優惠**: 作為山海圳國家綠道的合作夥伴，持有實體集章護照的旅人，在此訂房入住或進行餐飲消費時，可享有專屬折扣與禮遇（詳情請於訂房時洽詢或見現場公告）。
*   **鄰近景點**: 步出會館即可抵達八田與一紀念園區、天壇及香榭大道。

## 💡 旅人筆記
*   **住宿亮點**: 房間窗外即是如同「綠色珊瑚」般的湖景，清晨的霧氣更是如夢似幻。
*   **後勤整備**: 提供舒適的客房設施與餐廳服務，是長征路途中的精緻停靠站。
*   **進出提醒**: 入住旅人同樣需支付烏山頭水庫園區門票，但住宿可免除後續相關費用（具體以會館最新說明為準）。
