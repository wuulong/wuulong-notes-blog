# 十二佃神榕 (Twelve-Dian Sacred Banyan)

![20260130_zengwen_十二佃神榕](https://upload.wikimedia.org/wikipedia/commons/thumb/0/04/%E5%8D%81%E4%BA%8C%E4%BD%83%E7%A5%9E%E6%A6%95%E5%85%AC%E5%9C%92%E5%89%8D.jpg/1280px-%E5%8D%81%E4%BA%8C%E4%BD%83%E7%A5%9E%E6%A6%95%E5%85%AC%E5%9C%92%E5%89%8D.jpg)


## 簡介
位於安南區十二佃，這座巨大的榕樹林不僅是地方信仰中心，更是歷史上曾文溪氾濫區的「生物防禦工程」。

## 觀察重點
- **根系固堤**：觀察榕樹盤根錯節的根系如何與早期曾文溪的舊堤防結合，發揮抓穩土石、抵抗洪水沖刷的功能。這是在缺乏混凝土技術年代，先民智慧的體現。
- **精神防禦**：這是一種自然崇拜與水利防護的結合。神榕守護聚落的傳說，背後是科學性的防洪考量。
- **台江浮覆地**：此處位處 1823 年後台江內海浮覆的區域，可觀察周邊地勢與河流歷史軌跡的關係。
