# 榮華大壩 (Ronghua Dam)

## 📌 空間屬性
- **座標**：24.736944, 121.350833
- **類型**：混凝土重力拱壩 / 廢棄水利工程

## 📜 OO-History 考掘
- **【工程與自然的博弈】**：榮華大壩建於 1984 年，主要目的是為了拦截大漢溪上游的泥沙，以延長下游石門水庫的壽命。
- **【廢墟化地層】**：由於大漢溪上游地質脆弱（多為砂頁岩與崩塌地），大壩在經歷數次颱風暴雨後，泥沙淤積率迅速達到 **100%（完全淤滿）**。大壩功能完全喪失，並在 2004 年艾利颱風時發生左岸崩塌、壩體受損。
- **【考掘意義】**：這是一個極具象徵意義的「工程殘骸」。它以立體的混凝土物理實體，無聲地見證了人類以水泥工程試圖規訓高山荒溪侵蝕力量的抗衡史，以及自然力量最終對人類設施的「徹底接收」。
