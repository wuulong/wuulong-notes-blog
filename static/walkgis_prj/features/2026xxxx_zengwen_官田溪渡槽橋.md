# 官田溪渡槽橋

## 簡介
嘉南大圳跨越官田溪的水道橋。與曾文溪渡槽橋、茄拔溪渡槽橋併稱為嘉南大圳三大渡槽橋。

## 觀察重點
- **桁架結構**：觀察日治時期鋼結構工法。
- **水流方向**：確認嘉南大圳支線如何引導水源。
- **產業連結**：了解此區域與周邊農田灌溉之關係。
