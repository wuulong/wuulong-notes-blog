# 新園大排抽水站：強力抽排樞紐

![2026xxxx_gaoping_xinyuan_pump](https://lh3.googleusercontent.com/gps-cs-s/AHVAweqQtvmUZJGB5JOPoHfvp9gWtitweRzYhI-yAw3yXBfgWZCaqUmTO7womnnYUrG85PlONYBEA2EayH-NgnhVbc_X1erDNyNwTxvkt7-xbYtVGab0JK7ugkOY9LLm0__C9_oVGkuD_Q=s1600-w1200)


## 📜 歷史與地景背景
地勢極度低窪。抽水站運作與大潮水位、閘門開關密切連動。2-3月堤防木棉花盛開，增添人文層次。

## 🔍 流域深度解讀
負責調節仙吉村至港西村的排水。此處距離海岸線僅 6 公里，是年度大潮引發海水倒灌的關鍵防禦節點。

## ✨ 亮點特色
- 強力抽排樞紐
- 木棉花堤防
- 海水倒灌防線
