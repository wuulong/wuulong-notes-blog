# 宜蘭吳沙故居 (Wu Sha's Former Residence)

## 📌 空間屬性
- **座標**：24.7882519, 121.7593384
- **行政區**：宜蘭縣礁溪鄉吳沙村（昔稱四圍）
- **類型**：傳統民宅 / 歷史建築

## 📜 OO-History 考掘
- **【開墾原點】**：這裡是開蘭第一人吳沙的故居所在地。雖然現存建築為後世修築，但其選址緊鄰武暖石板橋，標誌著漢人移民在進入宜蘭平原後的首個穩定權力中心。
- **【防禦布局】**：故居周邊曾有護城河與刺竹圍，體現了開墾初期高度的不安全感與軍事化防禦邏輯。

## 📸 現場觀察筆記 (2026-05-15)
- 故居內的建築工藝呈現了清代中晚期的風格。
- 作為「四圍」的核心，這裡與北邊的「頭圍」及南邊的「五圍」形成了完整的歷史拓墾連線。
