# 六二溫泉山房 (62 Spring - Guidan)

## 簡介
龜丹溫泉是曾文溪流域上游重要的地熱資源。不同於關子嶺，這裡以無味、透明的弱鹼性碳酸氫鈉泉（美人湯）聞名。

## 觀察重點
- **地質能量**：理解曾文溪切穿山脈過程中，地表下溫泉脈穴的動態分布。
- **水中電療體驗**：觀測人體在清澈泉水中的感官回饋，思考自然資源在現代遊憩中的轉化。
- **山水共生**：在此休息點，回頭俯瞰流經楠西的曾文溪谷，感悟山林保水與出泉的連結。
