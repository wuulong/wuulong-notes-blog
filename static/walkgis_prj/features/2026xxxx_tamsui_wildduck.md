# 臺北市野雁保護區

## 簡介
臺北市野雁保護區位於新店溪中下游都會段（包含中興橋、華江橋、萬板橋至永福橋之間的水域與沙洲灘地）。因大漢溪與新店溪在此交匯，流速減緩，帶來大量有機泥沙沉積，發育出極為廣闊的濕地與高草叢沙洲。這裡每年冬季吸引數以萬計的雁鴨科與鷸鴴科候鳥在此過冬，是台北都會區最核心的野鳥自然棲地。

## 觀察重點
- **河川交匯與沙洲沉積**：觀察大漢溪與新店溪交匯處（江子翠附近）的水流動力減緩與泥沙沖淤地貌，特別是露出水面的大片潮汐泥灘地。
- **冬季候鳥與濕地生態**：在華江雁鴨自然公園或河濱步道，觀察小水鴨、綠頭鴨及各類鷸科鳥類的覓食活動，對比周邊林立的都市大樓。
- **都市汙水整治成效**：思考中下游河段如何從小兒麻痺般的「黑龍江」中重獲新生，並透過污水截流與濕地淨水逐步恢復鳥類生態的歷程。
