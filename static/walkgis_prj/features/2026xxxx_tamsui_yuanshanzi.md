# 員山子分洪道

## 簡介
員山子分洪道位於新北市瑞芳區，是基隆河防洪工程的核心關鍵設施。基隆河中上游因地勢陡峭且雨量豐沛，在歷史上常造成汐止、南港與五堵一帶的大水災。為了解決都會水患，政府興建此隧道，在洪峰期將上游多餘洪水直接導引至東海排入，成為世界級的無動力分洪工程。

## 觀察重點
- **堰體與攔河堰**：觀察基隆河道上的圓弧形攔河堰與側槽溢流堰，了解其如何利用物理高差自然引導洪水分流。
- **分洪隧道入口**：觀察直徑達 12 公尺的分洪隧道入口，想像大雨洪峰時水流排入隧道的壯觀動能。
- **分洪效益與水地景**：此處是「軟體定義防洪」與實體防洪的經典教材，對比基隆河中下游在興建分洪道前後的淹水歷史。
