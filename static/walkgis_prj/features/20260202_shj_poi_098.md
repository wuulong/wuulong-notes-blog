# 珈雅瑪文化園區 (Cayavama Culture Park)

![20260202_shj_poi_098](https://upload.wikimedia.org/wikipedia/commons/thumb/7/79/%E8%8C%B6%E5%B1%B1%E9%83%A8%E8%90%BD.jpg/1280px-%E8%8C%B6%E5%B1%B1%E9%83%A8%E8%90%BD.jpg)


位於嘉義縣阿里山鄉最南端的茶山部落 (Cayavama)，是一個融合了鄒族、布農族與漢族三族共榮的獨特文化場域。

## 🔍 特色與細節
*   **珈雅瑪之意**: 「Cayavama」在鄒族語中意為「山腰上的平原」。此地地形平緩，是阿里山山系中少見的開闊部落。
*   **涼亭分享文化**: 部落以「涼亭」(Hufu) 著名，涼亭是族人社交、休憩與分享收穫的場所。旅人在園區內能隨處感受這份「分享愛」的精神。
*   **三族融合美學**: 園區展現了三族傳統工藝與建築的交織，包括月桃編輯手工藝與各具特色的圖騰裝飾。

## 💡 旅人筆記
*   **部落巡禮**: 推薦參加園區提供的部落導覽，了解涼亭文化的起源及部落如何透過社區力量維持生態與傳統。
*   **體驗亮點**: 手搗麻糬與月桃鳥笛 DIY 是這裡最受歡迎的文化體驗活動，適合舉杯共飲小米酒後的動態休閒。
*   **交通節點**: 對於由大埔或曾文水庫區段正式進入阿里山原鄉的旅人，這裡是第一站視覺與靈魂的重擊。
