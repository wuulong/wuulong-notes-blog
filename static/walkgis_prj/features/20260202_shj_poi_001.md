# 隆田酒廠 (Longtian Distillery)

隆田酒廠位於臺南市官田區，是台灣菸酒公司旗下唯一結合生物科技與釀酒技術的「養生觀光酒廠」。這裡以生產優質高粱酒及傳統養生藥酒（如參茸酒、鹿茸酒）聞名。

## 📜 歷史沿革
*   **日治時期**: 前身為 1939 年成立的「番子田無水酒精工場」，二戰期間曾生產飛機用燃料。
*   **戰後轉型**: 1971 年成立隆田酒精精製工場，供應全國藥用及精製酒精。
*   **酒廠成立**: 1982 年開始生產高粱酒，正式定名為「隆田酒廠」。
*   **觀光化**: 2008 年擴建為「養生酒文化園區」，並於 2012 年結合「北蟲草」生物科技，轉型為現代化觀光工廠。

## ✨ 亮點特色
*   **北蟲草文化展示園區**: 全國唯一結合生技與釀酒的藥味養生園區，可近距離參觀北蟲草培養室。
*   **五感體驗**: 透過視覺、嗅覺、味覺等感官了解釀酒與生技栽培過程。
*   **深度導覽**: 免費入園，並提供專業的製酒工藝與養生知識導覽服務。

## 🍱 必吃美食與伴手禮
*   **酒廠限定**: 紅麴香腸、台酒冰棒、酒蛋、醉雞。
*   **特色小點**: 紅麴薄餅、北蟲草花雕雞絲麵（DIY體驗）。
*   **經典酒款**: 玉山高粱酒、長春酒、參茸酒。
