# 茄拔溪渡槽橋

![20260128_zengwen_茄拔溪渡槽橋](https://upload.wikimedia.org/wikipedia/commons/thumb/4/42/%E8%96%9C%E7%AE%96%E5%90%9F%E9%A4%A8%E9%88%94%E5%AD%98%28%E5%85%AD%29.djvu/page1-1280px-%E8%96%9C%E7%AE%96%E5%90%9F%E9%A4%A8%E9%88%94%E5%AD%98%28%E5%85%AD%29.djvu.jpg)


## 簡介
位於善化側，是嘉南大圳輸水系統中重要的跨河節點。其結構反映了當時精密的土木工程技術。

## 觀察重點
- **橋體細部**：觀察鉚釘與鋼樑之結合處。
- **河道景觀**：從橋上俯瞰茄拔溪與周邊地形。
