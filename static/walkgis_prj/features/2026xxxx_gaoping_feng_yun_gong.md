# 林園鳳芸宮：海巡媽文化

## 📜 歷史與地景背景
位於高雄林園，信仰範圍涵蓋廣大漁民聚落，是理解下淡水溪河口精神防禦的關鍵點。

## 🔍 流域深度解讀
以「海巡媽」聞名，媽祖金身會搭船出海巡視溪口，將神力由陸地延伸至變幻莫測的水域。這裡是高屏溪右岸最具代表性的海權信仰中心。

## ✨ 亮點特色
- 海巡媽文化
- 林園工業區並置
- 河口精神防禦
