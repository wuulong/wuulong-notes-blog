# 曾文水庫防淤隧道 (象鼻引水工)

## 簡介
曾文水庫防淤隧道是全台最大的消能防淤隧道，採「大斷面隧道」與「象鼻引水工」設計。其主要功能是在颱風期間排砂，利用水頭壓力將底部淤泥排出，延長水庫壽命。

## 觀察重點
- **象鼻引水工**：位於水庫水面下之進水口結構。
- **消能池**：隧道出水口巨大的水躍消能設施。
- **排砂量**：了解每年預計排砂量與水庫續作能力。
