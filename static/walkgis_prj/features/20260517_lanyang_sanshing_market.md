# 三星公有零售市場 (Sanshing Market)

## 📌 空間屬性
- **座標**：24.665185, 121.6518477
- **類型**：傳統市場 / 庶民生活空間

## 📜 OO-History 考掘
- **【生活物件】**：市場作為平原邊緣物資交換與生活積累的核心空間。
- **【感官震撼】**：市場內的平平價海鮮粥。老闆曾是餐廳大廚，目前純粹做興趣，用料誇張至極。在小地方的市場竟然被老闆問要不要吃點「黑鮪魚」，體現了地方飲食文化深藏的驚喜地層。
