# 內洞國家森林遊樂區

## 簡介
內洞國家森林遊樂區位於新北市烏來區，處於南勢溪與內洞溪的交匯處。此處因內洞溪封閉的地形與瀑布群，擁有全台名列前茅的負離子含量。它是新店溪上游南勢溪水系的核心水源保護區，孕育了豐富的蕨類生態與潮濕森林地景。

## 觀察重點
- **內洞瀑布（三層瀑布）**：觀察內洞溪受地質構造與斷層影響形成的壯觀瀑布群，感受豐沛的負離子與水文動力。
- **南勢溪與內洞溪交匯**：觀察主流南勢溪與支流內洞溪的匯流處，水流顏色與流速的對比。
- **水源涵養林**：沿途步道觀察茂密的副熱帶雨林與蕨類生態，理解上游森林如何發揮涵養水源、穩定大台北民生水源命脈的功能。
