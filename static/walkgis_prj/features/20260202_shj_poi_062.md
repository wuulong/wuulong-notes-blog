# 台南市紅樹林保護協會 (Tainan Mangrove Protection Association)

![20260202_shj_poi_062](https://lh3.googleusercontent.com/gps-cs-s/AHVAwepxSPLPgxrPaHsZXAF_p7feQDrBihnjAHPPE9kmXeqOgYKsgTXRG_pBnhKX9OtPoEPHiGksxnKwV-M5gEuxdFoa-6mVC2fo1nx_iXpkJuwZGWLeltvjqEBeAHZs0Lq6VHabsFqv=s1600-w1200)


位於台南安南區四草大道，協會致力於保育台江內海珍貴的紅樹林濕地與生態文化，是山海圳國家綠道「內海之路」極具環境教育意義的民間組織。

## 🔍 特色與細節
*   **濕地守護者**: 協會成立於 1993 年，長期推動四草地區紅樹林與濕地的保育、研究與推廣工作。
*   **四草湖導覽**: 與當地資源結合，協助提供深入四草湖與紅樹林隧道的生態解說服務，讓民眾近距離觀察水鳥、招潮蟹與彈塗魚。
*   **綠道服務**: 這裡是了解台江地區如何從荒蕪沙洲演變為生態寶庫的最佳入口。

## 💡 旅人筆記
*   **生態觀察**: 推薦在此停留參與生態解說，能讓你更深刻理解山海圳綠道「海拔 0 公尺」處多樣化的生物生命力。
*   **集章與補給**: 協會相關據點常與台江遊客中心銜接，提供旅人豐富的自然知識補給。
