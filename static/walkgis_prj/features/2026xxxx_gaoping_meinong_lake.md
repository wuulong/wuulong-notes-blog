# 美濃湖(中正湖)：客庄重要蓄水

![2026xxxx_gaoping_meinong_lake](https://upload.wikimedia.org/wikipedia/commons/4/43/Meinong-chong-chieng-lake.jpg)


## 📜 歷史與地景背景
原名彌濃湖，興建於乾隆年間，是典型的人造農業景觀與生態濕地。

## 🔍 流域深度解讀
高屏溪上游支流的重要蓄水設施，調節客家聚落耕種節奏。美濃粄條的口感便源於此等清純水源。

## ✨ 亮點特色
- 客庄重要蓄水
- 水鳥棲地
- 清純伏流水
