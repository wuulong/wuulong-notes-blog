# 左鎮老街奉茶室 (Zuozhen Old Street Tea Room)

## 簡介
座落在無明顯指標、僅幾百公尺長的左鎮老街上。這裡是左鎮化石園區旁的隱藏景點，保留了最純粹的平地河谷聚落氛圍。

## 觀察重點
- **非景觀景觀**：體驗這條「差點錯過」的老街，觀察其歷史建築與純樸生活感，與官方策展的巨大博物館形成強烈對比。
- **奉茶的人文溫度**：老街奉茶室提供的休息點，是長途探索流域中的溫暖座標。
- **地緣政治遺溫**：此區域曾是曾文溪支流與史前地層交錯的地點，觀察老街聚落的選址規律與河流的關係。
