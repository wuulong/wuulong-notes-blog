# 護照優惠-阿里山森林遊樂區入口售票亭 (Alishan Forest Area Ticket Booth)

阿里山國家森林遊樂區入口售票亭是山海圳國家綠道「聖山之路」段落的核心門戶。

## 🔍 特色與細節
*   **護照持有者優惠**: 為了鼓勵綠道徒步者，持有「山海圳國家綠道集章護照」的旅人，在此購買園區門票時可享有優待票價格（具體金額依林管處現場公告為準）。
*   **入園第一關**: 這裡是所有進入阿里山遊樂區展開深山健行的起點，也是獲取園區最新地圖與氣象資訊的地方。

## 💡 旅人筆記
*   **身分確認**: 購票時請主動出示實體護照，以便售票人員核對。
*   **補給提醒**: 通過售票亭後即進入轉運站與商店區，是前往塔塔加前最後的大型補給點。
*   **交通接駁**: 鄰近阿里山轉運站，可由此轉乘前往塔塔加或嘉義市區。
