# 林園海洋濕地公園：倒立水母奇觀

![2026xxxx_gaoping_linyuan_wetland](https://lh3.googleusercontent.com/gps-cs-s/AHVAweqK9UX_20IwfbCeBfpzhiRYgZw8HD3UmpQJV7E1oPjghFkTanQDKmjC86Wlu_Z156cJ6AScMiuo40MNU57i8hj9NxWz-0cmgjCcjPsqLgNTK-orUA-ghrCXt_X78ibSjsIBvtY=s1600-w1200)


## 📜 歷史與地景背景
地處古西溪潟湖遺蹟。每年9月至隔年5月，「倒立水母」會大量聚集。呼吸根與皮孔結構是潮間帶生存智慧的視覺化呈現。

## 🔍 流域深度解讀
全臺唯一可見「仙后水母」（倒立水母）的天然潟湖，擁有150年歷史的海茄苳紅樹林。在重工業環繞下，展現極強的生態韌性。

## ✨ 亮點特色
- 倒立水母奇觀
- 150年海茄苳
- 古西溪潟湖遺構
