# 林園海洋濕地公園：倒立水母湖

## 📝 景點簡介
全臺唯一可見「仙后水母」（倒立水母）的天然潟湖。這裡也保存了超過150年的原生海茄苳紅樹林。

## 🔍 流域深度解析
1. **海茄苳老樹**：
   在重工業包圍的林園區，此處是古西溪潟湖的遺構。呼吸根與皮孔結構是潮間帶生存智慧的視覺化呈現。每年9月至隔年5月是觀賞倒立水母的最佳時機。
2. **探索觀點**：
   造訪此地時，請注意觀察其作為高屏溪「生存過濾系統」或「歷史傷痕」的具體細節。

## ✨ 亮點特色
- 倒立水母湖
- 海茄苳老樹
- 工業補償生態
