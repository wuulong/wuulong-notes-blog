# 大漢溪石門河川襲奪點

## 簡介
大漢溪石門河川襲奪點位於今日桃園石門水庫下游、石門大坑附近。在距今約三萬年前的更新世晚期，原本流經此處的大漢溪（古大漢溪）是往西北流向桃園台地直接入海。然而，地勢較低的古新店溪（古淡水河）因強烈的向源侵蝕作用，切穿了石門附近的山谷，襲奪了古大漢溪的上游。這使得大漢溪在此處產生了近乎 90 度的直角向北轉折，流向台北盆地，形成了今日淡水河水系的宏偉地貌。

## 觀察重點
- **直角彎曲河道地形**：從石門高處（如石門山或壩頂）觀察大漢溪流出石門峽谷後，突然向北北東直角轉彎流向大溪的曲流地貌。
- **斷頭河與襲奪河地形對比**：理解襲奪後，桃園台地上的河流（如老街溪、南崁溪）因失去大漢溪上游水源而成為「斷頭河」，而淡水河則成為流量大增的「襲奪河」。
- **水利工程與地質關聯**：思索石門水庫之所以能建於此狹窄峽谷中，正是因為這段因襲奪而強烈下切的V型地質山谷所提供的優異壩址條件。
