# 📍 寶桑 (Baosang)

## 📜 歷史背景
「寶桑」是台東市的老地名，源於卑南族語 "Paposogan"。在清領時期是卑南溪口的重要聚落與貿易點。

## ✨ 亮點特色
- **歷史地位**: 曾設有昭忠祠，紀念開山撫番陣亡將士。
- **地理位置**: 位於卑南溪入海口南側。
