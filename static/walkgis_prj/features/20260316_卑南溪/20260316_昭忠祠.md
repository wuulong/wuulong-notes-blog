# 📍 昭忠祠 (Zhaozhong Shrine)

## 📜 歷史背景
光緒七年（1881年）由同知袁聞柝建於寶桑海濱，紀念開山撫番陣亡將士。後於1888年番亂中被燬，1892年重建於鰲魚山。

## ✨ 亮點特色
- **紀念意義**: 台灣開山撫番歷史的重要見證。
- **現況**: 台東天后宮旁亦設有相關紀念空間。
