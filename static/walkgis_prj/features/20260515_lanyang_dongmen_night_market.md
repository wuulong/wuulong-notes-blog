# 宜蘭東門觀光夜市 (Dongmen Night Market)

## 📌 空間屬性
- **座標**：24.7581411, 121.7584576
- **行政區**：宜蘭縣宜蘭市
- **類型**：觀光夜市 / 生活空間

## 📜 OO-History 考掘
- **【生活地層】**：夜市位於舊宜蘭城的東門區域（震安宮附近），是城市防禦體系消失後，由庶民生活填充而成的動態空間。
- **【社交媒介】**：透過美食（如一串心、蔥油餅），夜市成為族群與世代交融的非正式社交地景。

## 📸 現場觀察筆記 (2026-05-15)
- 夜市不僅是觀光點，更是本地人晚餐與社交的核心。
- 觀察到攤位布局與鐵路高架下的空間利用，呈現了現代宜蘭城的空間適應性。
