# 台南市西拉雅文化協會 (Tainan Siraya Culture Association)

台南市西拉雅文化協會成立於 1998 年，是長期致力於推動平埔族群權益、語言復振與身份正名的關鍵社會團體。

## 🔍 特色與細節
*   **權益與正名運動**: 協會是爭取西拉雅族納入法定原住民族身分的核心力量。2024 年更見證了憲法法庭判決後的重大正名進度。
*   **語言復振**: 積極推動西拉雅語的教材研發與教學，讓曾經被認為消失的語言重新在校園與部落中響起。
*   **文化學術站點**: 協會整理並保存了大量關於西拉雅族遷徙史、公廨信仰與傳統歲時祭儀的文獻與口述歷史。

## 💡 旅人筆記
*   **理解台灣之魂**: 徒步山海圳綠道，本質上就是穿梭在西拉雅族人的傳統領地（從台江海岸到山區）。透過了解協會的努力，旅人能更深刻共感這塊土地原本的主人是如何堅持守護其尊嚴。
*   **諮詢與互動**: 若想深入了解西拉雅專法、語言學習資源或各部落夜祭時間，此處是專業的諮詢窗口。
