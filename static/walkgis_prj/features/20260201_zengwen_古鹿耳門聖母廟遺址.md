# 古鹿耳門聖母廟遺址

## 簡介
見證 1823 年曾文溪大改道後，原鹿耳門聖母廟遭洪水沖毀的歷史遺產。

## 觀察重點
- **滄海桑田**：理解當年洪水如何改變地理景觀，毀壞原有的宏偉廟宇。
- **信仰傳承**：觀察當地居民如何在災後遷徙，並在浮覆地重新建立起現今規模龐大的聖母廟。
- **碑石刻記**：尋找紀錄大改道與毀廟歷史的相關碑石或刻記。
