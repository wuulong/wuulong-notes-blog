位芋園南邊的聚落，為一山區較大的平坦地面而得名，此地為大坪村的本庄，人口較多，房屋較密集。

史料記載：
[農業志] 大坪林圳：在拳山堡。莊民合築，源出青潭溪，灌田四百六十五甲。
[農業志] 大坪林圳：在拳山堡。莊民合築，源出青潭溪，灌田四百六十五甲。
[列傳三] 郭元汾，字錫琉，漳人也。乾隆間來臺，居淡水大佳臘堡。墾田樹穀，擁資厚。時拳山一帶多荒土，而水利未興。乃傭工鑿圳，引新店溪之水，自大坪林築陂蓄之，穿山度，至溪仔口，又引至挖仔內，過公館街，抵內埔，分為三。溝澮縱橫，長數十里。臺北近附之田皆資灌溉，凡千數百甲。既成，名金合川圳，而佃人念其功，稱琉公圳。
