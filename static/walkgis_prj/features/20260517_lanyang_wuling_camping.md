# 武陵農場露營區 (Wuling Camping Area)

## 📌 空間屬性
- **座標**：24.380966, 121.304847
- **類型**：露營地 / 車宿據點

## 📜 OO-History 考掘
- **【車宿適應】**：豪華分區營位並附設小吃部，雖然露營區提供供電，但對於自主發電系統完善的探索者來說並非必要，選擇停靠於小吃部旁提供了極佳的生活便利性。這是首次在車宿旅程中支付住宿費的定錨點。
- **【星空地層與光害】**：無雲的高山天氣提供了極為壯觀的滿天星空，躺在馬路上仰望宇宙，與千百年前在此定居的古人共享同一片星斗，體驗強烈的「時空重疊感」。
- **【空間局限】**：由於營區燈光幽靜，對觀星而言光害稍大；且周圍松林與樹林密集，使得星空視野被樹梢切割，只露出一半，展現了「被地貌物件分割的星空」。
