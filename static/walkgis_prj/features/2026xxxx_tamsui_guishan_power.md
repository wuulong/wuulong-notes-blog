# 龜山水力發電所遺址

## 簡介
龜山發電廠（舊稱龜山水力發電所）建於日治時期明治三十六年（1903年），並於1905年完工發電。它坐落於南勢溪與北勢溪匯合至新店溪之「雙溪口」（今新店龜山），是**台灣歷史上第一座水力發電廠**。當年架設的輸電線路送至古亭變電所，讓台北三市街（大稻埕、艋舺、城內）首次大放光明，奠定了台灣現代電力事業與工業化的起點。

## 觀察重點
- **雙溪口水文匯流點**：觀察「北勢溪」與「南勢溪」交匯成新店溪主流的雙溪口地形，體會兩溪合流時的急流動力。
- **電力事業歷史地景**：走訪老發電廠的建築遺跡（新龜山發電廠/桂山發電廠附近），感受日治初期開創性水利發電的歷史空間。
- **水資源與電力聯動**：理解南勢溪與北勢溪豐沛且穩定的常年流量，如何為台灣早期工業現代化提供源源不絕的潔淨動能。
