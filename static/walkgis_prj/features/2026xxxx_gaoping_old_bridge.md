# 舊下淡水溪鐵橋：飯田豐二設計

## 📝 景點簡介
昔日東洋第一長橋。斷裂的桁架是1970年代非法採砂導致河床劇烈下降（沈箱基礎失去側向支撐）的殘忍見證。

## 🔍 流域深度解析
1. **採砂掏空斷橋**：
   2005年海棠颱風洪水只是臨門一腳，真正的殺手是數十年來抽砂船對河基的掏空。目前的「天空步道」讓訪客能步入這歷史傷痕的上方。
2. **探索觀點**：
   造訪此地時，請注意觀察其作為高屏溪「生存過濾系統」或「歷史傷痕」的具體細節。

## ✨ 亮點特色
- 飯田豐二設計
- 採砂掏空斷橋
- 鋼鐵殖民象徵
