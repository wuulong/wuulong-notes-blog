# 舊下淡水溪鐵橋：飯田豐二單華倫式桁架

![2026xxxx_gaoping_old_bridge](https://upload.wikimedia.org/wikipedia/commons/thumb/8/85/%E4%B8%8B%E6%B7%A1%E6%B0%B4%E6%BA%AA%E9%90%B5%E6%A9%8B%EF%BC%88%E9%AB%98%E5%B1%8F%E6%BA%AA%E8%88%8A%E9%90%B5%E6%A9%8B%EF%BC%89-1.jpg/1280px-%E4%B8%8B%E6%B7%A1%E6%B0%B4%E6%BA%AA%E9%90%B5%E6%A9%8B%EF%BC%88%E9%AB%98%E5%B1%8F%E6%BA%AA%E8%88%8A%E9%90%B5%E6%A9%8B%EF%BC%89-1.jpg)


## 📜 歷史與地景背景
1913年完工，2005年斷橋。目前轉化為天空步道，俯瞰高屏溪主流與生態轉生的濕地。

## 🔍 流域深度解讀
曾為東洋第一長橋。斷裂處見證了1970年代猖獗採砂導致河床劇烈下降（沈箱裸露），最終被颱風沖斷的悲劇。

## ✨ 亮點特色
- 飯田豐二單華倫式桁架
- 採砂經濟傷痕
- 國定古蹟天空步道
