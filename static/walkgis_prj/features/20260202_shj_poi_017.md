# 菱炭森活工場 (Trapa Shell Bio-charcoal Living Workshop)

![20260202_shj_poi_017](https://lh3.googleusercontent.com/places/ANXAkqGdXlNazoELTyW42ay67zR7f82B9a_4codLd1jwk_2oWTl_shp7--zM4JG9dV9d--Hza4nG_hslMz7F6brZKgQmWubDq3_OLbY=s1600-w1200)


位於台南市官田區，是全台灣唯一以「菱角殼炭化」為主題的觀光工廠。官田身為台灣菱角的主要產地，每年產生大量廢棄菱殼，工場透過專利技術將其轉化為高價值的「菱殼炭」，成功落實農業循環經濟，並賦予廢棄物「烏金」的新生命。

## 🔍 特色與細節
*   **農業烏金傳奇**: 菱角殼炭化後具備優異的吸附異味與空氣淨化功能。園區展示了從原料收集、多階低氧熱解到產出高品質菱殼炭的完整製程。
*   **循環經濟體驗**: 
    - **DIY 活動**: 提供水泥盆器製作、造型吸附包 DIY 等體驗，讓遊客親手將低碳理念帶回家。
    - **熱能再利用**: 園區內的「官田窯」與「烏金灶」利用炭化過程產生的餘熱進行烹飪，體現能源不浪費的智慧。
*   **環境教育據點**: 這裡是山海圳綠道行經官田時，極佳的生態與環保教育站，透過導覽能深入理解土地、作物與環境復育的關聯。

## 💡 旅人筆記
*   **預約制服務**: 為確保導覽與體驗品質，工場採取 **預約制**，造訪前請務必提前聯繫確認。
*   **在地好物**: 推薦選購由菱殼炭開發的吸附包、除臭襪或相關藝品，支持在地永續產業。
*   **美食特色**: 園區有提供獨特的「菱角鮮奶露」及特色預約料理，適合補給體力。
