# 台南楠西區照興里篤加阿立祖公廨 (Zhaoxing Alizu Ancestral Shrine)

![20260202_shj_poi_063](https://lh3.googleusercontent.com/gps-cs-s/AHVAwer25zwAv2gIDEJeYP0yat4nooBZRHswHSGvLhN-_EQce624RvKCViZffDqIZRyI6SfONBLdqMkaUGzGnb0DImR9P6XANVJxVQ5xhCUlspO86XaCMVLT58KLFTPYcHYEFHKSssOJ=s1600-w1200)


位於台南市楠西區照興里（灣丘地區），此公廨是西拉雅平埔族祖靈信仰「阿立祖」的重要祭祀空間。它是山海圳國家綠道中，展現族群融合與多元信仰並存的珍貴文化節點。

## 🔍 特色與細節
*   **瓶壺信仰**: 與一般漢人神像信仰不同，此處供奉代表阿立祖靈力的陶瓶、水罐。祭祀時通常會插入蘆葦、甘蔗或澤蘭葉。
*   **篤加阿立祖**: 雖然「篤加」原為七股地區的地點，但隨著族群遷徙與信仰流派傳播，「篤加太祖」成為台南多處平原與山線公廨共同尊崇的聖號。
*   **文化遺存**: 楠西地區在歷史上曾是平埔族與大武壠族遷徙的區域。照興里公廨的存在，見證了西拉雅文化在山麓地帶的延續。

## 💡 旅人筆記
*   **文化尊重**: 進入公廨參觀時請保持肅靜，嚴禁隨意觸碰祭壇上的瓶壺與祭品。若有祭典（如夜祭）舉行，請遵循當地長輩引導。
*   **周邊人文**: 這裡鄰近曾文水庫區，周邊為純樸的農村聚落。徒步者行經此處，可深刻感受到台灣土地上多元文明交會的厚度。
