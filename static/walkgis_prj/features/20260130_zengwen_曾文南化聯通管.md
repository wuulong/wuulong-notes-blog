# 曾文南化聯通管 (Zengwen-Nanhua Interconnection Pipeline)

![20260128_zengwen_曾文南化聯通管](https://upload.wikimedia.org/wikipedia/commons/thumb/4/43/05.08_%E7%B8%BD%E7%B5%B1%E8%A6%96%E5%AF%9F%E3%80%8C%E6%9B%BE%E6%96%87%E5%8D%97%E5%8C%96%E8%81%AF%E9%80%9A%E7%AE%A1%E5%B7%A5%E7%A8%8B%E8%A8%88%E7%95%AB%E3%80%8D.jpg/1280px-05.08_%E7%B8%BD%E7%B5%B1%E8%A6%96%E5%AF%9F%E3%80%8C%E6%9B%BE%E6%96%87%E5%8D%97%E5%8C%96%E8%81%AF%E9%80%9A%E7%AE%A1%E5%B7%A5%E7%A8%8B%E8%A8%88%E7%95%AB%E3%80%8D.jpg)


## 簡介
這是近年南部最重要的水資源穩定計畫「東水西送、南供水珍珠串」的核心工程。透過巨大的聯通管，雙向調度曾文水庫與南化水庫的水源。

## 觀察重點
- **技術韌性**：聯通管可分散單一水庫淤積或暴雨混濁導致的供水風險。
- **沿線地質工程**：管線穿梭在不穩定的泥質邊坡中，觀察其防震與監測設施。
- **跨流域調度意志**：思考河流（曾文溪與後堀溪）在物理上透過人工管線進行「數位化」調配的現代管理模式。
