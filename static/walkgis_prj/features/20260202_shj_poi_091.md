# MT.Sylvia Coffee 雪山貓

![20260202_shj_poi_091](https://lh3.googleusercontent.com/gps-cs-s/AHVAweqjzUDdMn3Trfd6D9alKaksl7w7WKjzIZnutbWXiZ-NnEdghWio_gFf4sWEpzSpqg7JkM3rczxLBfrCVwYnm6hHav9Bb3NnUxFS8Sm_U44cRmg4571GfNnl31xJN2SRHsrcW97C=s1600-w1200)


位於台南安南區的獨棟純白玻璃屋咖啡館，「雪山貓」是山海圳國家綠道「內海之路」段落中一個極具質感與設計感的精品咖啡站點。

## 🔍 特色與細節
*   **阿里山咖啡之窗**: 店內專注推廣台灣阿里山莊園咖啡。特色推薦其設計感十足的高山形狀冰塊飲品，將阿里山的意象微縮於杯中。
*   **歐義美學料理**: 除了精品手沖，也提供高品質的早午餐、義大利麵與職人甜點。
*   **建築空間**: 採光極佳的玻璃屋設計，讓旅人在市區中也能感受到如同山林間的通透感，是記錄綠道旅途心情的絕佳休憩空間。

## 💡 旅人筆記
*   **出發前的沈靜**: 適合由台江起點出發後的首站停留，在這裡品一口阿里山咖啡，為接下來 177 公里的山海挑戰做心理上的預熱。
*   **環境氛圍**: 裝潢充滿文藝氣息且安靜，是數位遊牧者與徒步旅行者沈澱思緒的好地方。
