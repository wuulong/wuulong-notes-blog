# 烏山頭水庫

![20260131_zengwen_烏山頭水庫](https://upload.wikimedia.org/wikipedia/commons/thumb/9/9e/Coral_Lake_Tainan_from_airplane_window.JPG/1280px-Coral_Lake_Tainan_from_airplane_window.JPG)


## 簡介
由八田與一技師設計，於 1930 年完工。是嘉南大圳最核心的蓄水設施，透過引水隧道攔截曾文溪的水源。

## 觀察重點
- **珊瑚潭地景**：觀察其曲折的湖岸線，了解「半水力填築式」土霸的建築特色。
- **送水閘門**：嘉南大圳的輸水起點，感受供水流量的宏偉。
- **遊船體驗**：從水面視角觀察庫區地理。
