# 噍吧哖事件紀念園區 (Tapani Incident Memorial Park)

![20260130_zengwen_噍吧哖事件紀念園區](https://lh3.googleusercontent.com/gps-cs-s/AHVAweq6xVOxSBbuZoVBlRoWH-ZblSmCvxAXpo26gjCYfRCBnNsDFuXkiCuLVJlaG-hdZYsX1ijBmQb6MxsH0qrqHG9zDv7TofUZbGTBjAH9OjcArAX5cNYWDVb9zeytfACXNfslk00-=s1600-w1200)


## 簡介
位於玉井糖廠舊址，此處紀錄了 1915 年規模最大的武裝抗日事件「噍吧哖事件」（又稱西來庵事件）。透過歷史建築的活化，展現了河流流域中族群、生存與政權更迭的沉重記憶。

## 觀察重點
- **歷史即視感**：展間詳述了江定、余清芳等人的抗日戰略，其移動路線與曾文溪山區地形緊密結合。
- **時光電話體驗**：利用互動裝置聽取模擬的罹難者家屬語音，將枯燥的歷史數字轉化為真實的感官情感連結。
- **糖業遺跡**：觀察原玉井糖廠的建築格局，理解糖業經濟如何形塑今日的玉井城鎮空間。
