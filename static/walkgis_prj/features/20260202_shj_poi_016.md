# 臺南山上花園水道博物館 (Tainan Shanshang Garden水道Museum)

臺南山上花園水道博物館（原臺南水道）是台灣公權衛生現代化的重要里程碑。這座結合歐式工業美學與花園景觀的博物館，不僅是全台規模最大的水道古蹟，也是認識台灣近代生活史的必訪站點。

## 📜 歷史背景 (Historical Context)
*   **都市之生的源頭**: 始建於 1912 年，1922 年竣工啟用。由英國工程師巴爾頓與「台灣水道之父」濱野彌四郎規劃設計，解決了當時臺南市區長年受霍亂等流行病困擾的問題。
*   **世紀退役**: 供水長達 60 年，於 1982 年因曾文水庫與潭頂淨水廠完工而正式退役。
*   **古蹟重啟**: 2002 年指定為國定古蹟，歷經多年修復後於 2019 年以「花園水道博物館」之名重啟，轉型為科普教育與休閒場域。

## ✨ 亮點特色 (Highlights & Features)
*   **快濾筒室 (Rapid Filter Room)**:
    - **工業美學**: 館內整齊排列著 14 座從英國購入的藍色大型快濾筒，搭配高挑的木構屋頂，是館內最具震撼力與設計感的景觀。
*   **送出唧筒室**: 
    - **巴洛克外觀**: 具備厚實紅磚牆與大型窗櫺，內部保存了當年的火力發電設備基座與水泵組件。
*   **淨水池區 (需另行步行)**: 
    - **石造碉堡**: 位於水源地山上，需攀爬 189 階好漢坡。外觀猶如歐洲古城堡，並有 59 座鑄鐵通氣噴口，氣氛神祕幽靜（同時也是蝙蝠棲息地）。
*   **花園與藝術**: 園區廣達 36 公頃，散布多件大地藝術作品，並設有「八田水池」供親子戲水，將冰冷的水利工程轉化為親民的藝術空間。
