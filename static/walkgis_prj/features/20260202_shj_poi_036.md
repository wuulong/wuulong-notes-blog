# 山海驛站-官田工作站 (Guantian Irrigation Station)

![20260202_shj_poi_036](https://upload.wikimedia.org/wikipedia/commons/thumb/f/f3/CADAL09009595_%E5%96%84%E5%BE%8C%E6%95%91%E6%BF%9F%E7%B8%BD%E7%BD%B2%E5%8F%B0%E7%81%A3%E5%88%86%E7%BD%B2%E6%A5%AD%E5%8B%99%E7%B8%BD%E5%A0%B1%E5%91%8A_-_%E6%B0%91%E5%9C%8B%E4%B8%89%E5%8D%81%E5%9B%9B%E5%B9%B4%E5%8D%81%E4%B8%80%E6%9C%88%E8%87%B3%E4%B8%89%E5%8D%81%E5%85%AD%E5%B9%B4%E4%BA%94%E6%9C%88.djvu/page1-1280px-CADAL09009595_%E5%96%84%E5%BE%8C%E6%95%91%E6%BF%9F%E7%B8%BD%E7%BD%B2%E5%8F%B0%E7%81%A3%E5%88%86%E7%BD%B2%E6%A5%AD%E5%8B%99%E7%B8%BD%E5%A0%B1%E5%91%8A_-_%E6%B0%91%E5%9C%8B%E4%B8%89%E5%8D%81%E5%9B%9B%E5%B9%B4%E5%8D%81%E4%B8%80%E6%9C%88%E8%87%B3%E4%B8%89%E5%8D%81%E5%85%AD%E5%B9%B4%E4%BA%94%E6%9C%88.djvu.jpg)


官田工作站位於台南市官田區，隸屬於農田水利署嘉南管理處烏山頭分處。這裡是守護「烏山頭水庫」下游第一線灌溉網絡的重要據點，肩負著管理官田區廣大農田配水與設施維護的任務。

## 🔍 特色與細節
*   **大圳幹線核心**: 最初建於 1930 年，名為「官田幹線監視所」。官田站的地理位置極佳，負責監控嘉南大圳幹線進入官田精華區後的流量分配。
*   **菱角之鄉的推手**: 官田地區以生產高品質菱角聞名，官田站精準的水位管理，是確保這片豐饒土地能孕育出優質作物的關鍵。
*   **現代水利智慧**: 目前已全面導入智慧水管理系統。站長可透過電子閘門遠端調節供水，展現了傳統水利建設邁向數位轉型的成果。

## 💡 旅人筆記
*   **驛站補給**: 為行經山海圳「大圳之路」官田段落的旅人提供基礎諮詢與空間指引。
*   **文資漫遊**: 工作站建築體雖經整修，但周邊仍保留了早期的水利工程氛圍，非常適合作為理解大圳歷史與現場運作的活教材。
*   **推薦動線**: 官田工作站鄰近「隆田 chacha」與「官田遊客中心」，建議可串聯造訪，體驗從科技藝術到田野實作的完整水文化之旅。
