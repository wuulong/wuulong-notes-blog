# 住-福爾摩沙遊艇酒店 (Formosa Yacht Hotel)

![20260202_shj_poi_076](https://upload.wikimedia.org/wikipedia/commons/thumb/1/17/President_Lai_Ching-te_and_the_hostesses_at_the_state_dinner_banquet_2024-05-20.jpg/1280px-President_Lai_Ching-te_and_the_hostesses_at_the_state_dinner_banquet_2024-05-20.jpg)


位於台南安平水景橋旁，是全台首座擁有專屬遊艇碼頭的文創酒店。它為山海圳國家綠道「內海之路」的起點提供了一種奢華且具備海洋視野的住宿體驗。

## 🔍 特色與細節
*   **私家碼頭意象**: 酒店與安平古堡隔灣相望，建築設計融合了湖景、碼頭與台南在地文創元素，並設有高空無邊際泳池及 SPA 水療設施。
*   **景觀視野**: 房內大片落地窗可飽覽安平港的水色與夕陽，部分房型更可直接遠眺熱蘭遮城，是感受台南「海之門戶」魅力的絕佳地點。
*   **多功能樞紐**: 這裡不僅是高端住宿點，亦具備舉辦海濱婚禮與遊艇派對的功能，為傳統的安平港注入了現代奢華。

## 💡 旅人筆記
*   **啟程或慶功**: 作為全程 177 公里的起端（或終點）鄰近住宿，這裡非常適合作為出發前的體能充填，或是挑戰成功後犒賞自己的盛大慶功站。
*   **安平生活圈**: 步行即可抵達安平老街、安平古堡，方便旅人進行出發前的深度史蹟導覽。
