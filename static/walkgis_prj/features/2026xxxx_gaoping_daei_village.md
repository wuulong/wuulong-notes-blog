# 杉林大愛園區：空間規訓現場

## 📜 歷史與地景背景
安置那瑪夏、桃源災民。園區內的宗教圖騰與生活公約，引發了強烈的文化與生存權限拉鋸。

## 🔍 流域深度解讀
莫拉克災後最大安置點。灰瓦白牆的均質設計顯現了「慈善霸權」下的規訓空間，與原鄉部落地景形成反差。

## ✨ 亮點特色
- 空間規訓現場
- 慈濟美學與原民衝突
- 最大永久屋基地
