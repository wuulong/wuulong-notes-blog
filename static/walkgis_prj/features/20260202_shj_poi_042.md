# 烏山頭水庫風景區 (Wusanto Reservoir Scenic Area)

![20260202_shj_poi_042](https://upload.wikimedia.org/wikipedia/commons/thumb/f/ff/%E8%99%95%E5%AF%A6%E5%A0%82%E9%9B%86%28%E4%B8%89%29.djvu/page1-1280px-%E8%99%95%E5%AF%A6%E5%A0%82%E9%9B%86%28%E4%B8%89%29.djvu.jpg)


烏山頭水庫位於台南市官田區，因其蜿蜒的湖岸線酷似綠色珊瑚，故有「珊瑚潭」之稱。它是山海圳國家綠道「大圳之路」最重要的水利文化節點，見證了嘉南平原的富饒奇蹟。

## 📜 歷史背景 (Historical Context)
*   **八田與一的宏願**: 由「嘉南大圳之父」八田與一技師於 1920 年規劃興建，1930 年完工。當時是東亞規模最大、世界排名第三的土石壩工程。
*   **嘉南平原的血脈**: 這項工程結束了嘉南平原「看天田」的歷史，透過長達一萬六千公里的渠道網絡，將荒地變為良田，帶動台灣農業現代化。
*   **半水力沖淤式工法**: 水庫大壩採用獨特的「半水力沖淤式土石壩」工法（Semi-Hydraulic Fill），目前是世界上少數現存的此類結構。

## ✨ 亮點特色 (Highlights & Features)
*   **山海驛站與集章**:
    - **核心分段**: 位居山海圳「大圳之路」段，是徒步挑戰者的重要補給站。
    - **集章服務**: 提供山海圳國家綠道集章服務。
*   **文化地標**:
    - **八田與一紀念園區**: 包含修復的日式宿舍群與八田技師半身銅像，是感懷水利貢獻的必訪地。
    - **香榭大道**: 大壩下方種植一排南洋櫻，每年 3 月盛開時形成絕美櫻花隧道。
    - **天壇**: 園區內仿北京天壇縮小的建築，是知名的拍照熱點。
*   **自然生態**: 水庫周邊林木蒼鬱，可搭乘太陽能觀光船飽覽湖光山色，體驗寧靜的「夢之湖」。
