# 大白沙平台

綠島規模最大的沙體堆積區與海蝕平台，結合了生物造礁作用與機械式海蝕營力的動態界面。

## 📜 歷史背景 (Historical Context)
由碎珊瑚、貝殼與浮石構成的白沙與外海發達的珊瑚裙礁相連。在水理上，這裡是觀察綠島海岸「沉積流域」與「生態微流域」的最佳地點。

## ✨ 亮點特色 (Highlights & Features)
- **潛水步道**: 通往蔚藍深處的地景導引。
- **珊瑚礁多樣性能量**: 觀察不同種類硬珊瑚在潮汐與波浪壓力下的定居策略。
