# 碧潭與青潭水源地

## 簡介
碧潭與青潭堰位於新北市新店區，是新店溪水系民生用水與水利開發的核心交點。青潭堰是供應大台北地區數百萬人口自來水最重要的主要取水堰之一。而下游的碧潭則擁有歷史悠久的碧潭吊橋與著名的陡壁岩礁地景，兩者共同組成了新店溪最豐富的城市水源故事。

## 觀察重點
- **青潭堰防洪與取水**：觀察新店溪上的青潭堰大壩、取水口及相關取水設施，此處是翡翠水庫放水後進入淨水廠的主要門戶。
- **碧潭吊橋與岩壁**：觀察碧潭兩岸受河川切割形成的紅色陡峭岩壁（巨岩石壁地景），以及民國二十六年建造的碧潭吊橋鋼索歷史。
- **水質與民生關聯**：了解翡翠水庫－新店溪－直潭/公館淨水廠系統的運作方式。
