# 七股遊客中心

## 簡介
極具現代感的幾何建築，仿若海口沙洲地景。是進入七股鹽鄉與了解濕地生態的重要解說據點。

## 觀察重點
- **地誌解說**：透過展示了解曾文溪與七股潟湖、鹽田的演變關係。
- **現代建築地景**：灰白色調的階梯與斜面設計，呼應周邊的鹽山地誌景觀。
- **潟湖前哨**：作為進入七股潟湖遊船路徑前的知識補給站。
