# 護照販售-飛鼠咖啡 (Peisu Coffee)

![20260202_shj_poi_051](https://lh3.googleusercontent.com/gps-cs-s/AHVAweoNoTzuN4m03yFVWqyWIsXr62WsEG9t-IOjDqdjhh-4tqkyJd2rQrBJsD1MDHGo9WzIbtNUieyPaKOQnPA93ZPcjAoLnslPrZBMhu-t4c4OvviBqEUcDr-0oqnaq1Zx93JX8I0=s1600-w1200)


位於特富野部落的飛鼠咖啡 (Tfuya Peisu Coffee)，是一間融合鄒族獵人靈魂與現代咖啡工藝的預約制咖啡店。

## 🔍 特色與細節
*   **在地傳承**: 所使用的咖啡豆多由店主家族於部落高山區自行栽種。店名「Peisu」象徵著飛鼠，代表著店主對部落山林的熱愛與靈感來源。
*   **山海驛站據點**: 這裡是官方認證的山海圳驛站，提供實體護照販售服務。
*   **深度文化體驗**: 提供的不僅是飲品，更包括鄒族部落生活巡禮與文化解說教育。

## 💡 旅人筆記
*   **預約制服務**: 為確保服務品質與文化深度，造訪前請務必提前預約。
*   **補給節點**: 綠道徒步者在此蓋章或購買護照時，可與店主對談，獲取關於特富野地區第一手的野外步道與氣候資訊。
*   **在地好味**: 除了單品咖啡，推薦嘗試其與在地農產結合的創意飲品。
