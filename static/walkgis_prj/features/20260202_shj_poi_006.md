# 善化啤酒廠 (Shanhua Brewery)

位於台南市善化區，是台灣菸酒公司（TTL）在南台灣最重要的啤酒生產基地，供應量約佔全國三成。此廠於 1975 年完工，原名「成功啤酒廠」，後於 2005 年轉型為全台首座以啤酒為主題的文化園區，是結合工業生產與觀光休閒的重要據點。

## 🔍 特色與細節
*   **在地原料與水質**: 釀造啤酒主要使用嚴選大麥芽、啤酒花，並加入台灣優質蓬萊米作為副原料。水源取自曾文水庫，經過嚴格淨化處理，造就了台啤甘醇的口感。
*   **啤酒文物館**: 館內詳細展示了啤酒的製造工藝，從麥芽製作、糖化、發酵到包裝的完整過程，並完整記錄了台灣啤酒包裝與廣告的演進史。
*   **獨家特產**: 園區展售中心提供新鮮現榨生啤酒，以及結合在地風味的「芒果啤酒」。此外，還有麻油雞麵、酒蛋、酒粕面膜等台酒特色產品。
*   **啤酒公園改造**: 目前正推動景點美化計畫，預計將戶外空間打造為更具親和力的「啤酒公園」，包含景觀涼亭與綠地。

## 💡 旅人筆記
*   **免費參觀**: 園區內的文物館與產品中心皆可免費參觀，並附設廣大停車場，非常適合作為山海圳徒步或單車旅程的補給站。
*   **美食推薦**: 除了啤酒，廠內的紅麴香腸與台酒冰棒也是遊客必嚐的經典小食。
*   **理性飲酒**: 提供試飲服務，但切記「飲酒不開車，安全有保障」，單車旅者亦須注意飲酒後的生理反應。
