# 萬丹第一抽水廠：巴洛克機房建築

## 📝 景點簡介
完工於1928年的百年水利心臟。它將萬丹從旱田轉化為日治全台聞名的「高雄州糧倉」。

## 🔍 流域深度解析
1. **水往上流奇蹟**：
   建築具備巴洛克装饰元素。利用鯉魚山位差與泵浦動力創造的「水走天橋」，展現了日治時期仕紳集資與日本勸業銀行貸款的早期「地方創生」模式。
2. **探索觀點**：
   造訪此地時，請注意觀察其作為高屏溪「生存過濾系統」或「歷史傷痕」的具體細節。

## ✨ 亮點特色
- 巴洛克機房建築
- 水往上流奇蹟
- 仕紳集資興學
