# 山海驛站-茄拔天后宮 (Qieba Tianhou Temple)

![20260202_shj_poi_019](https://lh3.googleusercontent.com/gps-cs-s/AHVAwepu5I8Ia68X1Qiu-IunoAdviUhW_w--w8TsF9PVUjLR-7axO7TogV39DBDjbanO-2MpfwZ2xc1E9PU6MrDaS7E0YAWzk1cFZc4hC_apM2C8RFCDPukrnYCr3qB6ogWG10BnuIkc8zTZqnZn=s1600-w1200)


茄拔天后宮位於台南善化區，是山海圳國家綠道中極為重要的關鍵節點。它不僅是當地居民的信仰中心，更是綠道中「內海之路」（台江段）與「大圳之路」（官田段）的地理與文化交界處。

## 📜 歷史背景 (Historical Context)
*   **創建年代**: 茄拔天后宮創建於明永曆15年（西元1661年），淵源可追溯至先民跟隨鄭成功來台時，自湄洲迎請媽祖神像奉祀。
*   **鹿耳門請水**: 最具特色的傳統習俗。由於神像最初是在鹿耳門登陸，每四年廟方會帶領信眾回到鹿耳門「請水」，遙寄祖廟並感念先民開疆闢土的辛勞。
*   **地理意義**: 茄拔一詞源自平埔族語，顯示此地早期為西拉雅族與漢人交會地帶。在山海圳路徑中，此處正式從台江內海平原過度到嘉南大圳水利景觀。

## ✨ 亮點特色 (Highlights & Features)
*   **山海驛站服務**: 
    - 提供徒步者與單車騎士休憩空間。
    - **基礎設施**: 設有洗手間、飲水機供飲水補充。
    - **集章服務**: 綠道集章護照的指定結點。
*   **歷史建築**: 廟埕內有一口獲公告為歷史建築的古井，見證了茄拔聚落的發展史。
*   **建築藝術**: 華南三川式的建築風格，屋脊上的剪黏與石雕技藝精湛。

## 🍴 在地美食 / 服務資訊
*   **周邊美食**: 善化市區鄰近此地，以溫體牛肉湯最為出名。
*   **服務時間**: 廟宇開放時間內均可使用基本服務。
