# 淡江大橋

## 簡介
淡江大橋是跨越淡水河出海口、連接新北市淡水區與八里區的興建中地標性橋梁。由知名建築師扎哈·哈迪德（Zaha Hadid）事務所設計，為全球最長的不對稱單塔斜張橋。大橋的興建不僅是北台灣的交通要道，也是淡水河出海口的全新水文與地景景觀。

## 觀察重點
- **出海口景觀視野**：觀察淡水河水系流入臺灣海峽的壯闊河口，對比右岸沙崙與左岸挖子尾的岬角地形。
- **現代橋梁地景美學**：欣賞單塔斜張大橋的幾何結構與其「淡江夕照」背景的視覺呼應，思考現代交通工程與自然風景的融合。
- **都市與港灣擴展**：思考大橋落成後對淡水新市鎮與八里港區的都市水文和人流變遷影響。
