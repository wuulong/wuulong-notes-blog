# 集章處－0km 起點 (Taijiang National Park 0km Stamp Point)

![20260202_shj_poi_038](https://upload.wikimedia.org/wikipedia/commons/thumb/6/6d/%E5%8F%B0%E6%B1%9F%E5%9C%8B%E5%AE%B6%E5%85%AC%E5%9C%92%E4%B8%83%E8%82%A1%E5%A4%95%E7%85%A7.jpg/1280px-%E5%8F%B0%E6%B1%9F%E5%9C%8B%E5%AE%B6%E5%85%AC%E5%9C%92%E4%B8%83%E8%82%A1%E5%A4%95%E7%85%A7.jpg)


位於台江國家公園台江碼頭附近，此處是山海圳國家綠道（MSTW）引以為傲的海拔 0 公尺起點。對每一位準備踏上 177 公里長征的旅人而言，這裡象徵著從大海出發、向聖山致敬的莊嚴始點。

## 🔍 特色與細節
*   **山海之源**: 這裡不僅是地理上的 0 公里，更象徵著古台江內海的歷史源頭。旅人在此背後是大海、前方是貫穿嘉南平原直到玉山的壯闊軸線。
*   **室外集章功能**: 設有明顯的山海圳集章箱，供 24 小時自由造訪的旅人完成第一個「台江內海」的蓋印認證。
*   **綠道入口地景**: 周邊設有山海圳國家綠道的路線導覽看板與里程指標，幫助旅人建立完整的旅程視野。

## 💡 旅人筆記
*   **啟程儀式**: 到達此處蓋下第一個章，並在 0km 指標前合影，是完成山海圳全程挑戰最具儀式感的時刻。
*   **全天候開放**: 由於位於室外空間，不受場館營運時間限制。但建議在白晝造訪，以欣賞台江水岸與紅樹林的自然風光。
*   **補給與諮詢**: 蓋章後可進一步步行至鄰近的「台江國家公園遊客中心」，獲取更詳盡的摺頁資訊與館內諮詢服務。

## 📬 資訊卡
- **地址**: 臺南市安南區四草大道 118 號 (鄰近台江遊客中心水岸)
- **開放時間**: 全天開放 (室外集章箱)
- **核心功能**: 0km 起點認證、台江內海集章
