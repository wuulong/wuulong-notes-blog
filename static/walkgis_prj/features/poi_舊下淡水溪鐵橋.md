# 舊下淡水溪鐵橋

## 簡介
又稱『高屏舊鐵橋』，由飯田豐二設計，曾為東洋第一長橋。

## 探索筆記
*   **採砂傷痕**：觀察橋墩裸露與斷裂處，思考 1970-90 年代採砂經濟的代價。
*   **天空步道**：走上鐵軌，俯瞰下方濕地。
