# 蘭陽溪河床西瓜地景

## 簡介
蘭陽溪以含砂量高聞名，枯水期時露出的廣大砂質河床，成為孕育「蘭陽甜西瓜」的最佳溫床。這種隨季節變動的農業生產，形成了台灣獨特的河流地景。

## 觀察重點
- **砂質土讓**：觀察河床堆積的細砂與礫石，這提供了西瓜生長所需的優良排水性。
- **季節租契**：了解農民如何向河川局租用河床地，以及汛期到來前必須撤離的制度。
- **防風設施**：注意河床上常見的防風遮擋物，保護瓜苗免受蘭陽溪強大陣風襲擊。

## 💧 水利與地質解析
### 1. 輸砂特性
蘭陽溪的水力坡度大，上游板岩崩毀產生的細砂被迅速帶至平原段。由於河床寬闊且流速減緩，這些細砂在此沉降，形成了肥沃的有機質砂層。
### 2. 與洪水博弈
這是一種「逐水而居」的農業模式。農民必須在汛期（通常是 5 月之後）前完成收割，這套與大自然水位博弈的時間表，是蘭陽平原的人類行為與水文週期的深度結合。
