# 茂興懷舊步道 (Maoxing Reminiscent Trail)

## 📌 空間屬性
- **座標**：24.4828, 121.5422 (茂興站周邊)
- **類型**：森林步道 / 林業鐵道遺構

## 📜 OO-History 考掘
- **【鐵路物件】**：此處為蹦蹦車的終點。茂興線曾是太平山林場重要的運材軌道，現存的鐵道遺構展現了高山開採的空間規訓。
- **【自然演替】**：觀察鐵道兩側被苔蘚與蕨類覆蓋的枕木，這是一個「人工秩序回歸自然」的動態過程。

## 📸 現場觀察筆記 (2026-05-16)
- 走在軌道上能強烈感受到當年林業開發的規模。
- 森林層次豐富，是觀察中高海拔雲霧林生態的絕佳節點。
