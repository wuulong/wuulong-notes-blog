# 蘭陽冰廠金棗冰棒 (Lanyang Icebar - Kumquat Flavor)

## 📌 空間屬性
- **座標**：24.660511, 121.621443
- **類型**：地方冰廠 / 電力與產業副產品

## 📜 OO-History 考掘
- **【電力副產物件】**：源於蘭陽發電廠職工福利社。早期水力發電廠利用多餘的製冷與水源設施生產冰棒，現成為地方的標誌物。
- **【風味物件】**：金棗口味。將宜蘭在地特產「金棗」融入冰棒中，微酸微甜的獨特風味，反映了在地農業與工業水利系統的地緣結合。
