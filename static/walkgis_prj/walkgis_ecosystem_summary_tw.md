# 🗺️ WalkGIS 生態系：AI 友善的地理知識庫總覽

## 1. 專案理念：土地靈魂與空間邏輯
WalkGIS 是一個「數位地圖工廠」，致力於橋接冷冰冰的地理座標與溫暖的歷史敘事。它作為多個台灣重大河流探索計畫的**單一事實來源 (Single Source of Truth, SSOT)**。

**核心技術支柱：**
- **AI 友善架構**：採用 **SQLite** 搭配 **WKT (Well-Known Text)** 幾何字串，讓 LLM (大型語言模型) 能直接讀取並理解空間資料。
- **零依賴設計**：純文字與輕量資料庫結構，具備極高移植性。
- **拓樸邏輯**：使用 **Mermaid.js** 流程圖在 JSON 元數據中定義旅遊路徑與景點間的邏輯關聯。

---

## 2. 資源規模與多樣性
`walkgis_prj` 資源庫包含：
- **3,350+ 個原子特徵 (POI)**：每個點位皆包含 Markdown 格式的元數據、座標與歷史脈絡。
- **21+ 幅主題地圖定義**：結構化的資料集，涵蓋古圳路、水利工程、歷史地圖與災害防治等主題。
- **50+ 自動化腳本**：用於匯出 KML/GPX、生成 Google Maps 導航連結及 ATAK 數據包的工具。
- **9 個 SQL 管理模組**：標準化的 Schema 定義，確保圖層與關聯的一致性。

## 4. 自動化與 AI 代理工作流
WalkGIS 並非靜態存檔，而是一個**動態生成的系統**：
- **代理人協作 (Agentic Creation)**：AI 代理人可根據地點清單進行網路搜尋、生成 Markdown 特徵檔並自動注入 SQLite。
- **NotebookLM 協同**：內建萃取器，將密集的 GIS 資料蒸餾為 AI 易於理解的敘事引導（如課程投影片製作）。
- **空間匯出**：一鍵生成 KML/GPX，支援各類導航載具實地應用。

---

## 5. 元數據規格 (Layer 0-2)
- **Layer 0 (原始事實)**：精確座標與名稱。
- **Layer 1 (脈絡與標籤)**：分類、次分類與參考文獻。
- **Layer 2 (邏輯與 AI 專用)**：Mermaid 路徑定義（圖論架構）、關係權重及延伸之 `meta_data` JSON 擴充。
